# ShellMate UI 设计规范 v2 — 总纲与设计令牌

> 基于 Figma Make 原型（fileKey: upl5OBUkpLGnOe1u5aQRZ5）完全复刻

---

## 1. 设计语言总体原则

| 原则 | 描述 |
|------|------|
| **macOS 原生感** | 半透明磨砂玻璃层叠（backdrop-blur）、Apple 系统色、圆角卡片 |
| **轻量层次** | 三层景深：底层背景 → 面板层 → 覆层/弹窗 |
| **微动效** | 所有交互过渡 200ms，悬停阴影提升，选中态立即响应 |
| **极简信息密度** | 关键信息前置，次要信息用颜色降级而非删除 |

## 3. 排版令牌

| Token | 字号 | 字重 | 行高 | 用途 |
|-------|------|------|------|------|
| `text-hero` | 48px / 3rem | 700 Bold | 1.2 | 欢迎界面大标题 |
| `text-xl` | 20px | 500 Medium | 1.5 | 欢迎副标题 |
| `text-title` | 18px | 500 Medium | 1.5 | 弹窗标题（DialogTitle） |
| `text-body-lg` | 16px | 400 Normal | 1.5 | 正文、标签、按钮 |
| `text-body` | 14px | 500 Medium | 1.5 | 侧边栏会话名、工具栏文字 |
| `text-sm` | 13px | 400 Normal | 1.5 | 会话描述、弹窗描述 |
| `text-xs` | 12px | 500 Medium | 1.5 | 工具栏按钮标签、标签页标签 |
| `text-caption` | 11px | 400 Normal | 1.5 | 文件尺寸、时间戳、状态栏 |
| `text-terminal` | 14px | 400 Normal | 1.6 | 终端等宽字体（monospace） |

**字体栈：**
- UI 字体：系统默认（`-apple-system, BlinkMacSystemFont, "SF Pro Text"`）
- 代码/终端：`"Menlo", "Monaco", "Courier New", monospace`

## 7. 动效令牌

| Token | 值 | 用途 |
|-------|----|----|
| `duration-fast` | 200ms | 所有 hover、focus 状态切换 |
| `duration-normal` | 300ms | 面板展开、折叠 |
| `duration-slow` | 500ms | 欢迎界面步骤切换 |
| `easing-default` | `ease` | 通用缓动 |
| `easing-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 卡片悬停上浮（hover:-translate-y-1） |

## 8. 模糊效果

| 层级 | backdrop-blur 值 | 用途 |
|------|-----------------|------|
| 轻度 | `blur(8px)` | 工具栏、状态栏背景 |
| 中度 | `blur(16px)` | 侧边栏、标签栏 |
| 重度 | `blur(24px)` | 弹窗、覆层面板 |

## 9. 图标规范

统一使用 **Lucide React** 图标库，规格如下：

| 场景 | 尺寸 | 描述 |
|------|------|------|
| 工具栏图标 | 14px (h-3.5 w-3.5) | 按钮内图标 |
| 侧边栏图标 | 14px (h-3.5 w-3.5) | 会话行图标，文件夹图标 |
| 状态栏图标 | 12px (h-3 w-3) | CPU/内存/磁盘/网络图标 |
| 弹窗标题图标 | 20px (h-5 w-5) | TunnelManager、TmuxManager 等标题行 |
| AI头像图标 | 16px (h-4 w-4) | 消息气泡内头像 |
| 欢迎界面 | 28px (h-7 w-7) | 特性卡片内图标 |

## 10. 整体布局层次（Z 轴）

```
z-0   应用背景渐变（from-#f5f5f7 to-#e8e8ed）
z-10  主界面区域（标题栏 + 工具栏 + 侧边栏 + 终端 + 状态栏）
z-20  侧拉面板（AI 助手、文件传输）
z-30  悬浮面板（脚本自动化 fixed overlay）
z-40  对话框（弹窗 Dialog）
z-50  欢迎界面全屏遮罩
```
