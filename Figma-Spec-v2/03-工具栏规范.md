## 4. 按钮通用样式

```css
/* 文字按钮 */
variant="ghost" size="sm"
h-7 px-3 rounded-lg
hover:bg-black/5
text-[#1d1d1f] text-xs font-medium
transition-all duration-200

/* 图标按钮 */
variant="ghost" size="icon"
h-7 w-7 rounded-lg
hover:bg-black/5
text-[#1d1d1f]
transition-all duration-200

/* 禁用态 */
disabled:opacity-40
```
