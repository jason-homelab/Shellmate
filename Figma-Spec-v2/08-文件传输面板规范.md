---

```
┌─────────────────────────────────────────────────────────────────┐

├──────────────────────────────┬──────────────────────────────────┤
│  💻 本地                [+][🗑]│  🖥 远程                [+][🗑]│  双面板各含：标签+操作按钮

├──────────────────────────────┼──────────────────────────────────┤
│  📂  ..                       │  📂  ..                          │  滚动列表区
```

## 2. 容器规范

```css
h-full flex flex-col bg-white/50 backdrop-blur-xl
```

---

## 3. 顶部 Header

```css
p-3 border-b border-[#d2d2d7]/50
bg-white/60 backdrop-blur-xl shadow-sm
```

**标题行：**
```css
flex items-center justify-between mb-2
```

| 元素 | 规格 |
|------|------|
| 标题 | `text-sm font-semibold text-[#1d1d1f]`；内容："文件传输 - {sessionName}" |
| 上传按钮 | `h-7 px-3 rounded-lg text-xs ghost`；`Upload h-3 w-3 mr-1.5`；禁用：`selectedLocalFiles.size === 0` 或 `transferring` |
| 下载按钮 | `h-7 px-3 rounded-lg text-xs ghost`；`Download h-3 w-3 mr-1.5`；禁用：`selectedRemoteFiles.size === 0` 或 `transferring` |

**传输进度条（仅传输中显示）：**
```css
space-y-1 bg-white/80 backdrop-blur-sm p-2 rounded-lg

/* 顶行 */
flex items-center justify-between text-xs text-[#86868b]
→ 左："传输中: {filename}"  右："{progress}%"

/* 进度条 */
Progress value={progress} className="h-1.5"
```

## 4. 双面板布局

```css
flex-1 grid grid-cols-2 divide-x divide-[#d2d2d7]/50
```

### 4.1 面板头部（本地/远程各自）

```css
p-2 bg-white/60 backdrop-blur-xl border-b border-[#d2d2d7]/50
```

**标题行：**
```
[图标容器] 面板名称          [+][🗑]
```

| 面板 | 图标 | 图标色 | 图标背景 |
|------|------|--------|---------|
| 本地 | `HardDrive` | `text-[#007aff]` | `bg-[#007aff]/10` |
| 远程 | `Server` | `text-[#34c759]` | `bg-[#34c759]/10` |

操作按钮（`h-6 w-6 rounded-md hover:bg-black/5`）：
- `FolderPlus h-3 w-3`（新建文件夹）
- `Trash2 h-3 w-3`（删除，禁用：无选中文件）

**路径栏：**
```css
flex items-center gap-1
bg-white/90 backdrop-blur-sm rounded-lg
px-2 py-1.5
border border-[#d2d2d7]/50 shadow-sm
```

| 元素 | 规格 |
|------|------|
| Home 图标 | `Home h-3 w-3 text-[#86868b]` |
| 路径输入框 | `flex-1 text-xs bg-transparent outline-none text-[#1d1d1f]` |
| 刷新按钮 | `h-5 w-5 rounded-md hover:bg-black/5`；`RefreshCw h-3 w-3` |

## 5. 文件列表项

```css
w-full flex items-center gap-2
px-2 py-1.5 rounded-lg
text-left transition-all duration-200 group

/* 未选中 */
hover:bg-black/5

/* 选中（本地） */
bg-[#007aff]/10 border border-[#007aff]/30 shadow-sm

/* 选中（远程） */
bg-[#34c759]/10 border border-[#34c759]/30 shadow-sm
```

**文件行内部结构：**
```
[图标容器] 文件名（截断）        [>]
          尺寸 · 修改时间
```

| 元素 | 规格 |
|------|------|
| 目录图标容器 | `p-1 rounded-md bg-[#007aff]/10` |
| 目录图标 | `FolderOpen h-3.5 w-3.5 text-[#007aff]` |
| 文件图标容器 | `p-1 rounded-md bg-[#86868b]/10` |
| 文件图标 | `File h-3.5 w-3.5 text-[#86868b]` |
| 文件名 | `text-xs text-[#1d1d1f] truncate font-medium` |
| 元数据行 | `text-xs text-[#86868b] flex gap-2`（尺寸 + 日期） |
| 目录箭头 | `ChevronRight h-3 w-3 text-[#86868b]`；默认 `opacity-0`，`group-hover:opacity-100` |

---

## 6. 文件尺寸格式化

| 范围 | 显示 |
|------|------|
| `< 1024 B` | `{n} B` |
| `< 1 MB` | `{n} KB`（1位小数） |
| `< 1 GB` | `{n} MB`（1位小数） |
| `≥ 1 GB` | `{n} GB`（1位小数） |
| 无尺寸（目录） | `"-"` |
