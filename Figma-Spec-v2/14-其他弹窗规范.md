# ShellMate UI 设计规范 v2 — 其他弹窗规范

---

## 1. 分组管理（GroupManagementDialog）

### 1.1 弹窗规格

```
sm:max-w-[400px] bg-white/95 backdrop-blur-2xl
border border-[#d2d2d7]/50 shadow-2xl rounded-2xl
```

### 1.2 功能说明

- 列出所有已有分组（folders 数组）
- 新建分组：输入框 + 添加按钮
- 删除分组：每行末尾垃圾桶图标（二次确认，或直接删除）
- 删除后，该分组下的会话 folder 字段清空（归入"无分组"）

### 1.3 分组行样式

```css
flex items-center justify-between
py-2 border-b border-[#d2d2d7]/50

/* 文件夹图标 */
p-1.5 rounded-md bg-[#007aff]/10
Folder h-3.5 w-3.5 text-[#007aff]

/* 分组名 */
text-sm text-[#1d1d1f] flex-1 ml-2

/* 删除按钮 */
h-7 w-7 ghost hover:bg-red-50 hover:text-red-600
Trash2 h-3.5 w-3.5
```

## 2. 密码管理（PasswordManagerDialog）

### 2.1 弹窗规格

```
sm:max-w-[500px] bg-white/95 backdrop-blur-2xl
border border-[#d2d2d7]/50 shadow-2xl rounded-2xl
```

### 2.2 功能说明

- 列出所有已保存密码的会话（sessions 中 passwords Map 有记录的）
- 每行显示：会话名 + 主机 + 遮蔽密码（`••••••••`）+ 删除按钮
- 删除后从 passwords Map 中移除

### 2.3 会话密码行样式

```css
/* 容器 */
bg-white/80 backdrop-blur-sm rounded-xl
border border-[#d2d2d7]/50 p-3
flex items-center justify-between

/* 图标 */
p-1.5 rounded-md bg-[#ff9500]/10
KeyRound h-3.5 w-3.5 text-[#ff9500]

/* 会话名 */
text-sm font-medium text-[#1d1d1f]

/* 主机 */
text-xs text-[#86868b]

/* 密码遮蔽 */
text-xs text-[#86868b] font-mono "••••••••"

/* 删除按钮 */
h-7 w-7 ghost hover:bg-red-50 hover:text-red-600
Trash2 h-3.5 w-3.5
```

## 3. 导入/导出（SessionImportExportDialog）

### 3.1 弹窗规格

```
sm:max-w-[500px] bg-white/95 backdrop-blur-2xl
border border-[#d2d2d7]/50 shadow-2xl rounded-2xl
```

### 3.2 Tab 结构

```
┌────────────┐  ┌────────────┐
│   导出      │  │   导入      │
└────────────┘  └────────────┘
grid-cols-2 bg-black/5 rounded-xl p-1
```

**导出 Tab：**
- 会话列表（复选框选择要导出的会话）
- 格式选择：JSON / CSV
- 导出按钮（Download 图标）

**导入 Tab：**
- 文件拖拽区域（dashed 边框，上传图标）
- 或者文本框直接粘贴 JSON
- 导入按钮（Upload 图标）

## 5. 脚本自动化面板（ScriptAutomationPanel）

### 5.1 弹窗规格

全屏覆层（`fixed inset-0 z-50`），内容区域 `inset-4 bg-white/95 rounded-2xl shadow-2xl`

### 5.2 Header

```css
p-4 border-b border-[#d2d2d7]/50 bg-white/60 backdrop-blur-xl
flex items-center justify-between
```

**品牌图标：**
```css
p-2 rounded-xl
bg-gradient-to-br from-[#ff9500] to-[#ff6b00]
shadow-lg
```
图标：`Code2 h-5 w-5 text-white`

> ⚠️ 脚本自动化使用**橙色**品牌渐变（`#ff9500 → #ff6b00`），区别于 AI 的蓝紫渐变。

**标题文字：**
```css
font-semibold text-[#1d1d1f]   /* "Script Automation" */
text-xs text-[#86868b]          /* "Automate your workflows" */
```

**关闭按钮：**
```css
h-8 w-8 rounded-lg ghost hover:bg-black/5
X h-4 w-4
```

### 5.3 布局结构

```
┌──────────────────────────────────────────────────────────────────┐
│  [🟠] Script Automation                                   [×]   │  Header
│       Automate your workflows                                    │
├─────────────────────┬────────────────────────────────────────────┤
│  脚本库（左侧 w-64） │  编辑器（右侧 flex-1）                     │
│                     │                                            │
│  [🔍 搜索脚本]       │  ┌────────────────────────────────────┐   │
│  backup.sh          │  │  #!/bin/bash                       │   │  bg-[#1e1e1e]
│  deploy.sh    ●     │  │  # Backup script                   │   │
│  monitor.sh         │  │  echo "Starting backup..."         │   │
│                     │  │                                    │   │
│  ────────────────   │  └────────────────────────────────────┘   │
│  [● Record Session] │  执行日志                                   │  bg-black/5
│                     │  ┌────────────────────────────────────┐   │
│  [+ 新建脚本]        │  │  [12:34:56] Script started...      │   │
│                     │  │  [12:34:57] Backup complete        │   │
│                     │  └────────────────────────────────────┘   │
│                     │  [▶ Run] [💾 Save]                        │
└─────────────────────┴────────────────────────────────────────────┘
```

**左侧面板：**
```css
w-64 border-r border-[#d2d2d7]/50 flex flex-col
bg-white/60 backdrop-blur-xl
```

**脚本搜索框：**
```css
m-3 flex items-center gap-2 bg-white/80 rounded-lg
px-3 py-1.5 border border-[#d2d2d7]/50
Search h-3 w-3 text-[#86868b]
```

**脚本行：**
```css
px-3 py-2 rounded-lg cursor-pointer mx-2
hover:bg-black/5 text-[#1d1d1f]
/* 选中 */
bg-[#007aff] text-white
text-sm font-mono
```

**录制按钮（底部）：**
```css
m-3 h-8 px-3 rounded-lg text-xs
bg-[#ff3b30]/10 text-[#ff3b30] hover:bg-[#ff3b30]/20
Circle h-3 w-3 mr-1.5 animate-pulse（录制中）
```

**代码编辑区：**
```css
flex-1 bg-[#1e1e1e] rounded-xl p-4
text-[#cccccc] text-sm font-mono
outline-none resize-none
```

**执行日志区：**
```css
h-32 bg-black/5 rounded-xl p-3 overflow-y-auto
font-mono text-xs text-[#86868b]
```

**底部操作按钮：**
```css
/* 运行按钮 */
h-8 px-4 rounded-lg text-xs
bg-[#34c759] hover:bg-[#2fb350] text-white
Play h-3.5 w-3.5 mr-1.5

/* 保存按钮 */
h-8 px-4 rounded-lg text-xs ghost
border border-[#d2d2d7]/50
Save h-3.5 w-3.5 mr-1.5
```

## 6. 录制对话框（RecordingDialog）

```
sm:max-w-[500px] bg-white/95 backdrop-blur-2xl rounded-2xl
```

功能：录制终端操作（Terminal 会话回放）

状态指示：
- 未录制：灰色圆点
- 录制中：`bg-[#ff3b30] animate-pulse` 红色脉冲点
- 已录制：可回放

---

## 7. 日志查看器（LogViewerDialog）

```
sm:max-w-[800px] max-h-[85vh] bg-white/95 backdrop-blur-2xl rounded-2xl
```

功能：浏览历史保存的会话日志文件

列表：文件名、会话名、录制时长、日期  
操作：查看（全屏播放）、下载、删除

---

## 8. 弹窗统一规范汇总

| 属性 | 通用值 |
|------|--------|
| 背景 | `bg-white/95 backdrop-blur-2xl` |
| 边框 | `border border-[#d2d2d7]/50` |
| 阴影 | `shadow-2xl` |
| 圆角 | `rounded-2xl` |
| 标题字号 | `text-lg text-[#1d1d1f]` |
| 描述字号 | `text-sm text-[#86868b]` |
| 内部间距 | `gap-4` 或 `space-y-4` |
| 关闭手势 | 点击遮罩或 Esc 键 |
