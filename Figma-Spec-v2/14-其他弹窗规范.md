# Terminal Pro UI 设计规范 v2 — 其他弹窗规范

## 1. 分组管理（GroupManagementDialog）

### 1.1 弹窗规格

```
sm:max-w-[500px] bg-white/95 backdrop-blur-2xl
border border-[#d2d2d7]/50 shadow-2xl rounded-2xl
```

### 1.2 功能说明

- 列出所有已有分组（folders 数组）
- 新建分组：输入框 + 添加按钮
- 删除分组：每行末尾垃圾桶图标（二次确认，或直接删除）
- 删除后，该分组下的会话 folder 字段清空（归入"无分组"）

### 1.3 新建分组表单

```css
/* 输入框 + 按钮 行 */
flex gap-2

/* 输入框 */
Input placeholder="Production"
bg-white/80 backdrop-blur-sm border-[#d2d2d7]/50 rounded-lg shadow-sm

/* 新建按钮 */
bg-[#007aff] hover:bg-[#0051d5] text-white rounded-lg
FolderPlus h-4 w-4 mr-2
disabled: !newFolderName.trim() 或 folders 已包含该名称
```

### 1.4 分组列表样式

```css
/* 外层容器 */
border border-[#d2d2d7]/50 rounded-xl
divide-y divide-[#d2d2d7]/50 max-h-64 overflow-y-auto
bg-white/50 backdrop-blur-sm shadow-inner

/* 每行 */
flex items-center justify-between p-3
hover:bg-black/5 transition-all duration-200

/* 分组名 */
text-sm text-[#1d1d1f] font-medium

/* 删除按钮 */
h-7 text-red-600 hover:text-red-700 hover:bg-red-50 rounded-lg
Trash2 h-3 w-3 mr-1（text-xs）
```

## 2. 密码管理（PasswordManagerDialog）

### 2.1 弹窗规格

```
sm:max-w-[600px] bg-white/95 backdrop-blur-2xl
border border-[#d2d2d7]/50 shadow-2xl rounded-2xl
```

### 2.2 功能说明

- 列出所有已保存密码的会话（sessions 中 passwords Map 有记录的）
- 若无已保存密码，显示空态提示
- 每行显示：会话名 + 用户@主机 + 密码（可切换显示/隐藏）+ 删除按钮
- 删除后从 passwords Map 中移除

### 2.3 列表头

```css
text-xs text-[#86868b] mb-2 px-1
"{count} saved"
```

### 2.4 密码列表容器

```css
border border-[#d2d2d7]/50 rounded-xl
divide-y divide-[#d2d2d7]/50 max-h-96 overflow-y-auto
bg-white/50 backdrop-blur-sm shadow-inner
```

### 2.5 会话密码行样式

```css
/* 行 */
p-3 hover:bg-black/5 transition-all duration-200

/* 内部布局 */
flex items-start justify-between gap-4

/* 左侧文字区 */
  会话名: font-semibold text-sm text-[#1d1d1f]
  用户@主机: text-xs text-[#86868b] mb-2

  /* 密码显示行 */
  flex items-center gap-2

  /* 密码码块 */
  text-xs bg-black/5 backdrop-blur-sm px-3 py-1.5
  rounded-lg border border-[#d2d2d7]/50
  font-mono shadow-sm
  遮蔽: "•".repeat(12)
  显示: 实际密码字符串

  /* 切换按钮 */
  h-7 px-2 text-xs hover:bg-black/5 rounded-lg
  隐藏态图标: Eye h-3 w-3 mr-1
  显示态图标: EyeOff h-3 w-3 mr-1

/* 右侧删除按钮 */
h-7 text-red-600 hover:text-red-700 hover:bg-red-50 rounded-lg
Trash2 h-3 w-3 mr-1（text-xs）
```

## 3. 导入/导出（SessionImportExportDialog）

### 3.1 弹窗规格

```
sm:max-w-[600px] bg-white/95 backdrop-blur-2xl
border border-[#d2d2d7]/50 shadow-2xl rounded-2xl
```

### 3.2 Tab 结构

```
┌────────────┐  ┌────────────┐
│   Export   │  │   Import   │
└────────────┘  └────────────┘
grid-cols-2 bg-black/5 rounded-xl p-1
```

**导出 Tab（Export）：**

会话以 JSON 格式序列化后展示在只读 Textarea 中，用户可复制或下载：

```css
/* JSON 内容展示区 */
Textarea: rows={10} readOnly
bg-black/5 backdrop-blur-sm font-mono text-xs
border-[#d2d2d7]/50 rounded-xl resize-none

/* 操作按钮行（右对齐） */
flex justify-end gap-2

/* 复制按钮 */
variant="outline" h-8 px-3 text-xs
Copy h-3.5 w-3.5 mr-1.5（复制后变 Check，2s 后恢复）

/* 下载按钮 */
h-8 px-3 text-xs
bg-[#007aff] hover:bg-[#0051d5] text-white
Download h-3.5 w-3.5 mr-1.5
```

**导入 Tab（Import）：**

用户直接在文本框粘贴 JSON，或点击按钮上传文件：

```css
/* 粘贴区域 */
Textarea: rows={10} placeholder="Paste your JSON here..."
bg-black/5 backdrop-blur-sm font-mono text-xs
border-[#d2d2d7]/50 rounded-xl resize-none

/* 操作按钮行（右对齐） */
flex justify-end gap-2

/* 上传文件按钮 */
variant="outline" h-8 px-3 text-xs
Upload h-3.5 w-3.5 mr-1.5

/* 导入按钮 */
h-8 px-3 text-xs
bg-[#007aff] hover:bg-[#0051d5] text-white
disabled: JSON 文本为空时
```

## 4. 日志面板（LoggingPanel）

### 4.1 弹窗规格

```
sm:max-w-[900px] max-h-[80vh]
bg-white/95 backdrop-blur-2xl
border border-[#d2d2d7]/50 shadow-2xl rounded-2xl
overflow-hidden flex flex-col
```

### 4.2 布局结构

```
┌─────────────────────────────────────────────────────────────────┐
│  📋 Session Logs - {sessionName}               [清空][导出][暂停]│  标题行
├─────────────────────────────────────────────────────────────────┤
│  [🔍 搜索]              [Type: all ▼]  [Session ▼]             │  过滤行
├─────────────────────────────────────────────────────────────────┤
│  12:34:56  [command]  ls -la /home/ubuntu                       │  日志列表（ScrollArea）
│  12:34:57  [info]     total 48                                  │
│  12:34:58  [error]    Permission denied                         │
│  12:34:59  [warning]  Disk space low                            │
└─────────────────────────────────────────────────────────────────┘
```

**搜索框（左侧）：**
```css
flex items-center gap-2 bg-white/80 backdrop-blur-sm
rounded-lg px-3 py-1.5 border border-[#d2d2d7]/50
Search h-3.5 w-3.5 text-[#86868b]
input: text-xs bg-transparent outline-none placeholder:text-[#86868b]
```

**类型过滤下拉（Select）：**
```
选项：all / info / warning / error / command
h-7 px-3 rounded-lg text-xs
border border-[#d2d2d7]/50
```

**会话过滤下拉（Select）：**
```css
h-7 px-3 rounded-lg text-xs
border border-[#d2d2d7]/50
```

**日志行容器背景（按类型区分）：**
```css
info:    bg-white/80 border border-[#d2d2d7]/50
warning: bg-orange-50 border border-orange-200
error:   bg-red-50   border border-red-200
command: bg-blue-50  border border-blue-200
/* 通用：rounded-lg p-3 mb-1 */
```

**日志行内部布局：**
```css
/* 时间戳 */
text-xs text-[#86868b] font-mono w-20 flex-none

/* 类型徽章（文字颜色） */
error:   text-red-600
warning: text-orange-600
command: text-blue-600
info:    text-[#1d1d1f]（默认）
/* 尺寸 */
text-xs px-1.5 py-0.5 rounded-md font-medium

/* 内容 */
text-xs font-mono flex-1 ml-2
颜色与类型徽章一致
```

## 5. 脚本自动化面板（ScriptAutomationPanel）

### 5.1 弹窗规格

全屏覆层背景：`fixed inset-0 z-50 bg-black/30 backdrop-blur-sm`
内容区域：`absolute inset-4 bg-white/95 backdrop-blur-xl rounded-2xl shadow-2xl overflow-hidden flex flex-col`

### 5.2 Header

```css
p-4 border-b border-[#d2d2d7]/50 bg-white/60 backdrop-blur-xl
flex items-center justify-between
```

**品牌图标：**
```css
p-2 rounded-xl
bg-gradient-to-br from-[#ff9500] to-[#ff6b00]
shadow-lg
```
图标：`FileCode h-5 w-5 text-white`

> ⚠️ 脚本自动化使用**橙色**品牌渐变（`#ff9500 → #ff6b00`），区别于 AI 的蓝紫渐变。Header 图标为 `FileCode`（非 `Code2`）。

**标题文字：**
```css
font-semibold text-[#1d1d1f]   /* "Script Automation" */
text-xs text-[#86868b]          /* "Automate your workflows" */
```

**关闭按钮：**
```css
h-8 w-8 rounded-lg ghost hover:bg-black/5
X h-4 w-4
```

### 5.3 布局结构

```
┌──────────────────────────────────────────────────────────────────┐
│  [🟠] Script Automation                                   [×]   │  Header
│       Automate your workflows                                    │
├─────────────────────┬───────────────────────┬────────────────────┤
│  脚本库（左侧 w-64） │  代码编辑器（flex-1）   │  执行日志（w-96）  │
│                     │                       │                    │
│  ▾ Monitoring       │  #!/bin/bash           │ [12:34:56] started │
│    cpu_monitor.sh ● │  # Backup script       │ [12:34:57] done    │
│  ▾ Backup           │  echo "Starting..."    │                    │
│    backup.sh        │                        │                    │
│  ▸ Deployment       │                        │                    │
│  ▸ Maintenance      ├───────────────────────┤                    │
│  ▸ Security         │  [▶ Run]  [💾 Save]   │                    │
│  ▸ Custom           │                        │                    │
│  ─────────────────  │                        │                    │
│  [+ New Script]     │                        │                    │
│  [⏺ Record Session] │                        │                    │
└─────────────────────┴───────────────────────┴────────────────────┘
```

**左侧面板：**
```css

```

**分类标题行（可折叠）：**

## 6. 录制对话框（RecordingDialog）

```
sm:max-w-2xl bg-white/95 backdrop-blur-2xl
border border-[#d2d2d7]/50 shadow-2xl rounded-2xl
```

功能：录制终端操作，支持三阶段状态流转。

**三阶段状态：**

| 状态 | 描述 | 状态指示 |
|------|------|---------|
| Ready（待录制） | 显示开始按钮，说明文字 | 灰色圆点 |
| Recording（录制中） | 显示计时器 `mm:ss`，停止按钮 | `bg-[#ff3b30] animate-pulse` 红色脉冲 |
| Review（回放/回顾） | 已录命令列表展示于深色背景区块 | 绿色完成标记 |

**录制中状态：**
```css
/* 计时器 */
font-mono text-2xl font-semibold text-[#1d1d1f]

/* 停止按钮 */
bg-[#ff3b30] hover:bg-[#d0291f] text-white rounded-lg
Square h-4 w-4 mr-1.5
```

**Review 状态（已录命令列表）：**
```css
/* 命令列表容器 */
bg-[#1e1e1e] rounded-xl p-4 max-h-48 overflow-y-auto

/* 每条命令 */
text-xs font-mono text-[#cccccc]
```

**操作按钮（Review 阶段）：**
```css
/* 重录按钮 */
variant="outline" h-8 px-4 rounded-lg text-xs

/* 保存/完成按钮 */
h-8 px-4 rounded-lg text-xs
bg-[#007aff] hover:bg-[#0051d5] text-white
```

```
sm:max-w-[800px] max-h-[85vh] bg-white/95 backdrop-blur-2xl rounded-2xl
```

功能：浏览历史保存的会话日志文件

列表：文件名、会话名、录制时长、日期

## 8. 弹窗统一规范汇总

| 属性 | 通用值 |
|------|--------|
| 背景 | `bg-white/95 backdrop-blur-2xl` |
| 边框 | `border border-[#d2d2d7]/50` |
| 阴影 | `shadow-2xl` |
| 圆角 | `rounded-2xl` |
| 标题字号 | `text-lg text-[#1d1d1f]` |
| 描述字号 | `text-sm text-[#86868b]` |
| 内部间距 | `gap-4` 或 `space-y-4` |
| 关闭手势 | 点击遮罩或 Esc 键 |
