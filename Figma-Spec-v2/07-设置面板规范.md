## 2. Tab 标签规范

```css
/* TabsList */
grid w-full grid-cols-5
bg-black/5 backdrop-blur-sm rounded-xl p-1

/* 未选中 Tab */
rounded-lg transition-all duration-200

/* 选中 Tab */
data-[state=active]:bg-white
data-[state=active]:shadow-sm
```

## 9. 弹窗整体规范

| 属性 | 值 |
|------|-----|
| 最大宽度 | `sm:max-w-[600px]` |
| 最大高度 | `max-h-[80vh]` |
| 内容溢出 | `overflow-y-auto`（可竖向滚动） |
| 背景 | `bg-white/95 backdrop-blur-2xl` |
| 圆角 | `rounded-2xl` |
| 边框 | `border border-[#d2d2d7]/50` |
| 阴影 | `shadow-2xl` |
