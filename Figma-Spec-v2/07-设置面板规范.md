## 6. 颜色（Colors）Tab

> 此 Tab 用于管理**自定义配色方案**（Custom Color Schemes），非 ANSI 16 色编辑器。

```
│  Custom Color Schemes                          [+ Add Scheme]  │
│  Create and manage custom terminal color themes                │
│                                                                │
│  ┌──────────────────────────────────────────────────────────┐  │  (新建表单，点击 Add Scheme 展开)
│  │  Scheme Name: [Ocean Blue                ]               │  │
│  │  Background:  [色块] [#001f3f           ]               │  │  input[type=color] + hex文本框
│  │  Foreground:  [色块] [#7FDBFF           ]               │  │  grid grid-cols-2 gap-3
│  │  Cursor:      [色块] [#39CCCC           ]               │  │
│  │  Selection:   [色块] [#0074D9           ]               │  │
│  │                                  [Cancel] [Save Scheme]  │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                │
│  ┌──────────────────────────────────────────────────────────┐  │  已有配色方案卡片
│  │  Ocean Blue                                         [🗑] │  │
│  │  [BG #001f3f] [FG #7FDBFF] [Cursor #39CCCC] [Select #0074D9] │
│  └──────────────────────────────────────────────────────────┘  │
```

**配色方案卡片样式：**
```css
bg-white/80 backdrop-blur-sm rounded-xl
border border-[#d2d2d7]/50 p-3
hover:shadow-md transition-all duration-200
```

**新建表单容器：**
```css
bg-gradient-to-br from-[#007aff]/5 to-[#5856d6]/5
border border-[#007aff]/20 rounded-xl p-4 space-y-3
```

每个颜色字段：`input[type=color] w-12 h-9 p-1` + 文本框 `flex-1 font-mono text-xs`

**颜色预览色块（方案卡片底部）：**
```css
w-6 h-6 rounded border border-[#d2d2d7]
/* 旁边跟随：p标签 text-xs text-[#86868b]（BG/FG/Cursor/Select）+ code text-xs font-mono #hex */
```

```
│                                                 │

│  Allow AI-powered command suggestions...     ●│  Switch (默认开)
│                                                 │

│                                                 │

│  └───────────────────────────────────────────┘  │
```

**AI Provider 选项：**

| 值 | 显示名 | 可用模型 |
|----|--------|---------|
| `openai` | OpenAI | GPT-4 / GPT-4 Turbo / GPT-3.5 Turbo |
| `anthropic` | Anthropic (Claude) | Claude 3 Opus / Sonnet / Haiku |
| `google` | Google (Gemini) | Gemini Pro / Gemini Ultra |
| `azure` | Azure OpenAI | GPT-4 / GPT-3.5 Turbo |
| `ollama` | Ollama (Local) | Llama 2 / Mistral / Code Llama |
| `custom` | Custom Endpoint | Custom Model（显示自定义端点输入框） |

**保存按钮：**
```css
w-full rounded-lg
bg-[#007aff] hover:bg-[#0051d5] text-white
```
