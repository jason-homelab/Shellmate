# ShellMate UI 设计规范 v2 — 侧边栏（Sidebar）

---

## 1. 整体布局预览

```
┌──────────────────────────┐
│  Sessions     [+][⚙][🔑][⚙]  ← 顶部工具行 H:44px
├──────────────────────────┤
│                          │
│  ┌──────────────────────┐│
│  │ 🖥 Production S1     ││  ← 未选中会话行
│  │   admin@192.168.1.1  ││
│  └──────────────────────┘│
│  ┌──────────────────────┐│
│  │ 🖥 Dev Server        ││  ← 选中会话行（蓝底白字）
│  │   ubuntu@10.0.0.5    ││
│  └──────────────────────┘│
│                          │
│  ▶ 📁 Production    [3] │  ← 文件夹折叠行
│  ▼ 📁 Development   [2] │  ← 文件夹展开行
│    ┌──────────────────┐  │
│    │ 🖥 Server A      │  │  ← 文件夹内会话（缩进 16px）
│    │ 🖥 Server B      │  │
```

## 3. 顶部工具行

```
p-3 border-b border-[#d2d2d7]/50
flex items-center justify-between
backdrop-blur-xl bg-white/40
```

| 元素 | 规格 |
|------|------|
| 标题文字 | `text-sm font-medium text-[#1d1d1f]`，内容："Sessions" |
| 按钮容器 | `flex gap-1` |
| 按钮（4个） | `h-7 w-7 rounded-lg hover:bg-black/5 text-[#1d1d1f] transition-all duration-200` |
| 图标 | `h-4 w-4`；顺序：Plus（+新建）、FolderCog（管理分组）、KeyRound（密码管理）、Settings（设置） |

## 4. 会话行（Session Row）

### 4.1 未选中状态

```css
w-full text-left px-3 py-2 rounded-lg text-sm mb-1
transition-all duration-200
hover:bg-black/5 text-[#1d1d1f]
```

### 4.2 选中状态

```css
bg-[#007aff] text-white
shadow-md shadow-[#007aff]/30
```

### 4.3 内部布局

```
┌────────────────────────────────┐
│  ┌───┐  会话名（粗体，截断）    │  flex items-center gap-2
│  │ 🖥 │  user@host（细，截断） │
│  └───┘                         │
└────────────────────────────────┘
```

| 元素 | 规格 |
|------|------|
| 图标容器 | `p-1.5 rounded-md`；未选中：`bg-[#007aff]/10`；选中：`bg-white/20` |
| 图标 | `Server h-3.5 w-3.5` |
| 会话名 | `font-medium truncate` |
| 副标题 | `text-xs truncate`；未选中：`text-[#86868b]`；选中：`text-white/80` |

## 5. 文件夹行（Folder Row）

```
w-full text-left px-3 py-2 rounded-lg text-sm
hover:bg-black/5 transition-all duration-200
flex items-center gap-2 text-[#1d1d1f]
```

| 元素 | 规格 |
|------|------|
| 展开箭头 | `ChevronRight h-4 w-4 transition-transform duration-200`；展开时：`rotate-90` |
| 文件夹图标容器 | `p-1.5 rounded-md bg-[#007aff]/10` |
| 文件夹图标 | `Folder h-3.5 w-3.5 text-[#007aff]` |
| 文件夹名 | `font-medium` |
| 数量徽章 | `text-xs text-[#86868b] ml-auto bg-black/5 px-2 py-0.5 rounded-full` |

### 5.1 展开后的子会话

```css
/* 容器缩进 */
ml-4 mt-1
/* 子会话行样式与顶层会话行完全一致 */
```

---

## 6. 状态汇总

| 状态 | 视觉表现 |
|------|---------|
| 默认 | 文字 `#1d1d1f`，透明背景 |
| 悬停 | `bg-black/5`（5% 黑色遮罩） |
| 选中 | `bg-[#007aff]` 蓝底白字 + 阴影 |
| 文件夹折叠 | 箭头指向右（0°） |
| 文件夹展开 | 箭头旋转 90° |

---

## 7. ScrollArea

- 包裹会话列表的 `flex-1 overflow-y-auto` 区域
- 内部 `p-2` 内边距
- 使用 ScrollArea 组件，滚动条仅在 hover 时显示
