## 5. CPU 指示器

```
┌─────────────────────┐
│  🖥  CPU  32.1%     │
│  ↑    ↑     ↑       │
│ 图标  标签  数值     │
└─────────────────────┘
```

| 元素 | 规格 |
|------|------|
| 图标容器 | `p-1 rounded-md bg-[#007aff]/10` |
| 图标 | `Cpu h-3 w-3 text-[#007aff]` |
| 标签 | `text-[#86868b]` "CPU" |
| 数值 | `font-semibold`；颜色根据阈值：`<50%` → `#34c759`，`50-80%` → `#ff9500`，`>80%` → `#ff3b30` |

> ⚠️ **2026-04-03 更新**：CPU 仅显示图标 + 标签 + 百分比数值，**不显示迷你柱状图**。

## 8. 网络指示器

```
┌──────────────────────────────────────┐
│  📶  ↓ 45.2 KB/s   ↑ 12.1 KB/s     │
└──────────────────────────────────────┘
```

| 元素 | 规格 |
|------|------|
| 图标容器 | `p-1 rounded-md bg-[#34c759]/10` |
| 图标 | `Wifi h-3 w-3 text-[#34c759]` |
| 下行（↓） | 数值 `font-semibold text-[#34c759]` |
| 上行（↑） | 数值 `font-semibold text-[#007aff]` |

**单位格式：**
- `< 1 MB/s` → 显示 `KB/s`（值 × 1000 取整）
- `≥ 1 MB/s` → 显示 `MB/s`（保留 1 位小数）

---

## 10. 数据刷新频率

- 初始连接时立即设置随机初始值（CPU 20–80%、内存 4–12 GB、磁盘固定）
- 每 2000ms 更新一次（`setInterval`）
- 各指标变化量：CPU ±10%、内存 ±1 GB、网络 ±25 MB/s
- 断开连接时所有数值归零
