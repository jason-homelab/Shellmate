```
┌──────────────────────────────────────────────┐

│  └────┘                                      │
├──────────────────────────────────────────────┤
│                                              │
│  ┌────┐                                      │  AI 消息（左对齐）
│  │ ✨ │  Hello! I'm your AI terminal...     │
│  └────┘                                      │
│         ┌────────────────────────────┐  [U]  │  用户消息（右对齐）
│         │  How do I find large files? │       │

│  │ ✨ │  ●●●                               │
```

## 3. Header

```css
p-4 border-b border-[#d2d2d7]/50 bg-white/60 backdrop-blur-xl
```

**AI 品牌图标（Header 大图标）：**
```css
/* 外层容器：圆角矩形，非圆形 */
p-2 rounded-xl
bg-gradient-to-br from-[#007aff] to-[#5856d6]
shadow-lg
```
图标：`Sparkles h-5 w-5 text-white`

> ⚠️ Header 图标使用 `rounded-xl`（圆角矩形），消息气泡头像使用 `rounded-full`（圆形），两者不同。

**标题：**
```css
font-semibold text-[#1d1d1f]  /* "AI Assistant" */
text-xs text-[#86868b]         /* "Helping with {sessionName}" */
```

## 5. 命令块（Command Block）

位于 AI 消息气泡内部，有 `commands` 字段时显示：

```css
/* 整体 */
mt-3 space-y-2

/* 单条命令行 */
flex items-center gap-2
bg-black/5 backdrop-blur-sm
rounded-lg p-2
border border-[#d2d2d7]/30
```

| 元素 | 规格 |
|------|------|
| 命令文本 | `flex-1 text-xs font-mono text-[#1d1d1f] break-all`，`code` 标签 |
| 复制按钮 | `h-7 px-2 rounded-md hover:bg-black/10`；图标 `Copy h-3 w-3`；复制后变 `Check h-3 w-3 text-[#34c759]`，2秒后恢复 |
| 执行按钮（可选） | `h-7 px-2 rounded-md hover:bg-[#007aff]/10 text-[#007aff]`；图标 `Terminal h-3 w-3` |

## 6. Typing 指示器（AI 思考中）

```css
/* 外层同 AI 消息 */
flex gap-3

/* 气泡 */
bg-white/80 backdrop-blur-sm rounded-2xl px-4 py-3
border border-[#d2d2d7]/50 shadow-sm

/* 三点动画 */
flex gap-1
→ 3个 w-2 h-2 rounded-full bg-[#86868b] animate-bounce
→ animationDelay: 0ms / 150ms / 300ms（错开弹跳）
```

## 7. 快速提示（Quick Prompts）

仅在 `messages.length === 1`（只有初始欢迎消息）时显示：

```css
/* 容器 */
px-4 pb-3

/* 标题 */
flex items-center gap-2 mb-2
Lightbulb h-3.5 w-3.5 text-[#ff9500]
text-xs font-medium text-[#86868b]

/* 按钮组 */
flex flex-wrap gap-2
```

每个快速提示按钮：
```css
text-xs px-3 py-1.5 rounded-full
bg-white/80 backdrop-blur-sm
border border-[#d2d2d7]/50
hover:bg-[#007aff]/10 hover:border-[#007aff]/30
transition-all duration-200 text-[#1d1d1f]
```

预置快速提示内容：
- "How do I find large files?"
- "Check disk space"
- "Monitor CPU usage"
- "Create a backup script"

## 8. 输入区

```css
p-4 border-t border-[#d2d2d7]/50 bg-white/60 backdrop-blur-xl

/* 输入框行 */
flex gap-2
```

**Textarea：**
```css
min-h-[44px] max-h-32 resize-none
bg-white/80 backdrop-blur-sm
border-[#d2d2d7]/50 rounded-xl
shadow-sm focus:shadow-md
transition-all duration-200
rows={1}
placeholder="Ask me anything about terminal commands..."
```
快捷键：Enter 发送，Shift+Enter 换行

**发送按钮：**
```css
h-11 px-4 rounded-xl
bg-[#007aff] hover:bg-[#0051d5] text-white
shadow-lg shadow-[#007aff]/30
transition-all duration-200
disabled:opacity-40
```
图标：`Send h-4 w-4`；禁用：输入为空或 AI 回复中

**提示文字：**
```css
text-xs text-[#86868b] mt-2
"Press Enter to send, Shift+Enter for new line"
```
