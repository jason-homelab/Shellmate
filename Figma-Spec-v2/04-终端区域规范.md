# Terminal Pro UI 设计规范 v2 — 终端区域（Terminal Area）

---

## 1. 标签栏（Tab Bar）

```
┌──────────────────────────────────────────────────────────┐
│ [Production Server ×] [Dev Server ×] [Testing ×]         │
│  ↑ 选中态              ↑ 未选中态                         │
│  白底+阴影              透明底                            │
└──────────────────────────────────────────────────────────┘
H: 40px
bg-[#f5f5f7]/80 backdrop-blur-xl shadow-sm
border-b border-[#d2d2d7]/50
```

### 单个 Tab 规范

```css
/* 容器 */
h-10 rounded-none px-4
border-r border-[#d2d2d7]/50
relative group
transition-all duration-200

/* 未选中 */
bg-transparent text-[#1d1d1f]

/* 选中 */
data-[state=active]:bg-white/90
data-[state=active]:backdrop-blur-xl
data-[state=active]:shadow-sm
```

| 元素 | 规格 |
|------|------|
| 会话名 | `text-xs font-medium` |
| 关闭按钮（×） | `ml-2 h-5 w-5 inline-flex items-center justify-center rounded-md`；默认 `opacity-0`，hover 时 `opacity-100 hover:bg-black/10` |
| 关闭图标 | `X h-3 w-3` |

## 2. 终端视图（Terminal View）

### 2.1 容器

```css
h-full flex flex-col font-mono text-sm
background: theme.background  /* 根据主题变化，默认 #1e1e1e */
```

### 2.2 输出区域

```css
flex-1 overflow-y-auto p-4
color: theme.foreground
```

### 2.3 输出行类型

```
┌───────────────────────────────────────────────────────┐
│  ubuntu@prod-server:~$ ls -la          ← 输入行（input）│
│                       ────────                        │
│                   命令文字可 hover 显示 AI 说明 Tooltip │
│  Desktop  Documents  Downloads  Pictures  ← 输出行（output） │
│                                                       │
│  ⚠ bash: curl | sh: command not found  ← 错误行（error）│
│   ┌────────────────────────────────────┐              │
│   │ 💡 AI Suggestion                   │              │
│   │ Download and inspect the script... │ ← AI 建议条  │
│   └────────────────────────────────────┘              │
│                                                       │
│  ubuntu@prod-server:~$ _               ← 当前输入光标  │
└───────────────────────────────────────────────────────┘
```

### 2.4 Prompt 颜色

```css
color: theme.green  /* VS Dark: #4ec9b0, Monokai: #a6e22e 等 */
```

### 2.5 AI 命令说明 Tooltip

触发：鼠标悬停在命令文字上

```
┌───────────────────────────────────────────┐
│  ℹ Command Explanation                    │
│  Lists files and directories...           │
└───────────────────────────────────────────┘
absolute left-0 top-6 z-10
bg-[#1d1d1f] text-white
px-3 py-2 rounded-lg shadow-xl
border border-[#007aff]/30
max-w-md
animate-in fade-in slide-in-from-top-1 duration-200
```

| 元素 | 规格 |
|------|------|
| 图标 | `Info h-4 w-4 text-[#007aff] flex-shrink-0 mt-0.5` |
| 标题 | `text-xs font-semibold text-[#007aff] mb-1` |
| 内容 | `text-xs text-white` |

### 2.6 AI 错误建议条

当命令执行返回错误且 AI 有建议时显示：

```
┌───────────────────────────────────────────┐
│ ▌ 💡 AI Suggestion                       │  bg-[#ff9500]/10
│   Suggestion text...                      │  border-l-4 border-[#ff9500]
└───────────────────────────────────────────┘
mt-2 mb-2 px-3 py-2 rounded
```

| 元素 | 规格 |
|------|------|
| 图标 | `Lightbulb h-4 w-4 text-[#ff9500] flex-shrink-0 mt-0.5` |
| 标题 | `text-xs font-semibold text-[#ff9500] mb-1` |
| 内容 | `text-xs color: theme.foreground` |

### 2.7 当前输入行

```css
/* 输入 input 元素 */
flex-1 bg-transparent outline-none
color: theme.foreground
caretColor: theme.foreground
spellCheck: false
autoComplete: off
```

## 4. 终端主题切换

通过 SettingsDialog 的"终端"Tab 选择，影响以下 CSS 变量：

```
background  → 终端背景色
foreground  → 普通文字色
cursor      → 光标色
selection   → 选中高亮色
green       → Prompt 颜色
red         → 错误文字色
```
