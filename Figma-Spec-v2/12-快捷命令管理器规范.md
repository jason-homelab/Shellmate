## 5. 命令卡片

```css
bg-white/80 backdrop-blur-sm rounded-xl
border border-[#d2d2d7]/50
p-3 hover:shadow-md transition-all duration-200
```

**内部布局：**
```
命令名（粗体）                    [▶] [✎] [🗑]
描述文字（可选）
`命令内容（monospace）`
```

| 元素 | 规格 |
|------|------|
| 命令名 | `text-sm font-medium text-[#1d1d1f] mb-1` |
| 描述 | `text-xs text-[#86868b] mb-2` |
| 命令文本 | `text-xs bg-black/5 px-2 py-1 rounded block overflow-x-auto`，`code` 标签 |

**操作按钮（h-8 w-8）：**
| 按钮 | 图标 | hover 样式 |
|------|------|-----------|
| 执行 | `Play h-4 w-4` | `bg-[#007aff]/10 text-[#007aff]` |
| 编辑 | `Edit2 h-3.5 w-3.5` | `bg-black/5` |
| 删除 | `Trash2 h-3.5 w-3.5` | `bg-red-50 text-red-600` |
