## 2. 弹窗容器规范

```css
sm:max-w-[500px]
bg-white/95 backdrop-blur-2xl
border border-[#d2d2d7]/50
shadow-2xl rounded-2xl
```

---

## 3. 表单字段规范

所有输入框统一样式：

```css
bg-white/80 backdrop-blur-sm
border-[#d2d2d7]/50 rounded-lg
shadow-sm
focus:shadow-md
transition-all duration-200
```

---

## 4. 协议 Select 选项

| 值 | 显示名 |
|----|--------|
| `ssh` | SSH |
| `telnet` | Telnet |
| `serial` | Serial |

Select 弹出层：
```css
bg-white/95 backdrop-blur-xl
border-[#d2d2d7]/50 shadow-xl rounded-xl
```

---

## 5. 保存密码复选框

```css
/* Checkbox */
id="savePassword"

/* 文字标签 */
text-sm text-[#1d1d1f] cursor-pointer
```

---

## 6. 底部按钮规范

| 按钮 | 样式 | 禁用条件 |
|------|------|--------|
| 取消 | `variant="ghost" text-[#1d1d1f] hover:bg-black/5 rounded-lg` | 无 |
| 保存会话 | `bg-[#007aff] hover:bg-[#0051d5] text-white shadow-lg shadow-[#007aff]/30 rounded-lg disabled:opacity-40` | `!name \|\| !host \|\| !username` |

---

## 7. 字段验证规则

| 字段 | 必填 | 默认值 |
|------|------|--------|
| 会话名称 | ✓ | 空 |
| 主机 | ✓ | 空 |
| 端口 | ✓ | `22` |
| 用户名 | ✓ | 空 |
| 密码 | 否 | 空 |
| 分组 | 否 | 无分组 |

---

## 8. 保存后行为

1. 将会话添加至会话列表（`sessions` 状态）
2. 若勾选"保存密码"且密码非空，存入 `passwords` Map（Key: sessionId）
3. 重置表单所有字段为初始值
4. 关闭弹窗
