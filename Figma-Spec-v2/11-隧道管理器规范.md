## 6. 隧道卡片

```css
bg-white/80 backdrop-blur-sm rounded-xl
border border-[#d2d2d7]/50
p-4 hover:shadow-md transition-all duration-200
```

**内部布局：**
```
[●/○] 隧道名（粗体）      [Stop/Start] [✎] [🗑]
      描述文字
      [会话标签]
```

| 元素 | 规格 |
|------|------|
| 状态点 | `Circle h-3 w-3 mt-1`；active：`fill-green-500 text-green-500`；inactive：`fill-gray-400 text-gray-400` |
| 名称 | `text-sm font-medium text-[#1d1d1f] mb-1` |
| 描述 | `text-xs text-[#86868b] mb-1` |
| 会话标签 | `text-xs bg-[#007aff]/10 text-[#007aff] px-2 py-0.5 rounded`（inline-block） |

**状态切换按钮：**

| 状态 | 样式 | 文字 |
|------|------|------|
| active → 停止 | `h-8 px-3 text-xs bg-green-50 text-green-700 hover:bg-green-100` | "Stop" |
| inactive → 启动 | `h-8 px-3 text-xs bg-gray-50 text-gray-700 hover:bg-gray-100` | "Start" |

**编辑/删除按钮：**
- 编辑：`h-8 w-8 ghost hover:bg-black/5`；`Edit2 h-3.5 w-3.5`
- 删除：`h-8 w-8 ghost hover:bg-red-50 hover:text-red-600`；`Trash2 h-3.5 w-3.5`

---

## 7. 表单态字段

所有字段：
```css
Label: text-[#1d1d1f]
Input: bg-white border-[#d2d2d7]
```

**Tunnel Type Select 选项：**
| 值 | 显示 |
|----|------|
| `local` | Local Port Forwarding |
| `remote` | Remote Port Forwarding |
| `dynamic` | Dynamic SOCKS Proxy |

> 当 `type === "dynamic"` 时，**不显示** Remote Host 和 Remote Port 字段

---

## 8. 表单底部按钮

```css
flex gap-2 justify-end pt-2
```

| 按钮 | 样式 |
|------|------|
| Cancel | `variant="ghost" rounded-lg` |
| Add / Update Tunnel | `bg-[#007aff] hover:bg-[#0051d5] text-white rounded-lg`；禁用：`!name \|\| !localPort` |

---

## 9. 描述文字生成规则

| 类型 | 格式 |
|------|------|
| local | `"Local {localPort} → {remoteHost}:{remotePort}"` |
| remote | `"Remote {remotePort} → localhost:{localPort}"` |
| dynamic | `"Dynamic SOCKS proxy on port {localPort}"` |
