## Screen 08 — 弹窗 D04：端口转发管理器（隧道管理器）

### 08-A：面板规格

```
类型: Panel（浮动，可拖拽，非模态）
尺寸: 640 × 480pt
圆角: 10pt（macOS 窗口标准）
背景: Surface/Elevated
边框: Border/Default，1pt
阴影: 0 24pt 64pt rgba(0,0,0,0.75)

快捷键: ⌘⇧U
触发入口: 工具栏「隧道」按钮 / 菜单 Tools → Tunnel Manager
定位: 居中于主窗口，可拖拽移动
```

### 08-B：整体布局

```
Frame 尺寸: 640 × 480pt
布局: Vertical Auto Layout，间距 0

子区域（从上到下）:
  ① PanelHeader    640 × 44pt
  ② ToolbarRow     640 × 36pt
  ③ TableHeader    640 × 28pt
  ④ TableBody      640 × flex-1（可滚动，最小 180pt）
  ⑤ Divider        640 × 1pt   Border/Faint
  ⑥ DetailPanel    640 × 188pt（选中规则时展开）
```

### 08-C：面板标题栏（PanelHeader）

```
尺寸: 640 × 44pt
背景: Surface/Overlay
下边框: 1pt Border/Faint
内边距: 左 16pt 右 12pt，垂直居中

内部布局（水平，间距 0）:
  ├── 图标: SF Symbol「arrow.left.arrow.right」14pt Text/Tertiary
  │    右间距 8pt
  ├── 标题文字: "隧道管理器"  13pt SF Pro Medium  Text/Primary
  └── Spacer flex-1
  └── 关闭按钮: ×  14pt  22×22pt  圆角 4pt
        Default: Text/Disabled
        Hover:   背景 Surface/Overlay，Text/Secondary
```

### 08-D：工具栏行（ToolbarRow）

```
尺寸: 640 × 36pt
背景: Surface/Panel
下边框: 1pt Border/Faint
内边距: 左右 12pt，垂直居中

布局（水平，间距 0）:
  ├── [+ 新建规则] 按钮: Button/Bordered 高 26pt
  │    图标: SF Symbol「plus」11pt + 文字 11pt  间距 4pt
  └── Spacer flex-1
  └── 右侧按钮组（Auto Layout，间距 6pt）:
        [全部启动] 按钮: Button/Bordered 高 26pt
          图标: SF Symbol「play.fill」10pt  Text/Secondary
          文字: 11pt SF Pro Regular  Text/Secondary
        [全部停止] 按钮: Button/Bordered 高 26pt
          图标: SF Symbol「stop.fill」10pt  Text/Secondary
          文字: 11pt SF Pro Regular  Text/Secondary
```

### 08-E：表格表头（TableHeader）

```
尺寸: 640 × 28pt
背景: Surface/Panel
下边框: 1pt Border/Faint
内边距: 左右 12pt

布局（水平，垂直居中）:
  ┌──────────────────────────────────────────────────────────────┐
  │ 状态  │ 类型    │ 本地地址:端口        │ 远端目标        │ 绑定会话  │ 操作 │
  │ 32pt │ 72pt   │    flex-1          │   flex-1       │  100pt   │ 52pt │
  └──────────────────────────────────────────────────────────────┘

表头文字: 10pt SF Pro Medium  Text/Disabled  Uppercase  LS 0.04em
可点击排序列（类型/本地/远端/绑定会话）: cursor pointer，悬停 Text/Secondary
当前排序列: 列名右侧 SF Symbol「chevron.up」/「chevron.down」8pt  Accent/Default
```

### 08-F：隧道规则行（TunnelRow）

```
尺寸: 640 × 40pt（可变，内容决定高度）
下边框: 1pt rgba(255,255,255,0.02)
内边距: 左右 12pt，垂直居中

布局（水平，间距 0，垂直居中）:
  ├── 状态区（32pt）: StatusDot 6×6pt 居中
  ├── 类型区（72pt）: 类型标签 Badge
  ├── 本地地址（flex-1）: 11pt SF Mono  Text/Primary
  ├── 远端目标（flex-1）: 11pt SF Mono  Text/Secondary
  ├── 绑定会话（100pt）: 11pt SF Pro Regular  Text/Secondary，超出 ellipsis
  └── 操作区（52pt，Auto Layout 水平，间距 2pt）:
        暂停/启动按钮: IconBtn 20×20pt
          运行中: SF Symbol「pause.fill」  Text/Secondary
          已停止: SF Symbol「play.fill」  Accent/Default
        删除按钮: IconBtn 20×20pt
          SF Symbol「trash」  Text/Disabled
          Hover: Status/Error

行状态:
  Default:  背景透明
  Hover:    背景 Surface/Toolbar
  Selected: 背景 Accent/Glow，左侧 2pt Accent/Default 指示线
```

### 08-G：类型标签（TunnelTypeBadge）

```
  背景: rgba(199,125,255,0.15)

```

## Screen 09 — 弹窗 D05：快捷命令管理器

### 09-A：面板规格

```
类型: Panel（浮动，可拖拽，非模态）
尺寸: 560 × 460pt
圆角: 10pt
背景: Surface/Elevated
边框: Border/Default，1pt
阴影: 0 24pt 64pt rgba(0,0,0,0.75)

快捷键: ⌘⇧K
触发入口: 工具栏「命令」按钮（SF Symbol「list.bullet.rectangle」）
```

### 09-B：整体布局

```
Frame 尺寸: 560 × 460pt
布局: Vertical Auto Layout，间距 0

子区域（从上到下）:
  ① PanelHeader    560 × 44pt
  ② CommandSetBar  560 × 36pt
  ③ ContentArea    560 × flex-1（水平双栏）
  ④ Divider        560 × 1pt   Border/Faint
```

### 09-C：面板标题栏（PanelHeader）

```
尺寸: 560 × 44pt
背景: Surface/Overlay
下边框: 1pt Border/Faint
内边距: 左 16pt 右 12pt，垂直居中

内部布局（水平）:
  ├── 图标: SF Symbol「list.bullet.rectangle」14pt  Text/Tertiary  右间距 8pt
  ├── 标题: "快捷命令管理器"  13pt SF Pro Medium  Text/Primary
  └── Spacer flex-1
  └── 关闭按钮: ×  22×22pt（同 D04 规格）
```

### 09-D：命令集工具栏（CommandSetBar）

```
尺寸: 560 × 36pt
背景: Surface/Panel
下边框: 1pt Border/Faint
内边距: 左右 12pt，垂直居中

布局（水平，间距 8pt，垂直居中）:
  ├── 标签: "命令集："  10.5pt  Text/Disabled
  ├── Picker 「默认命令集 ▼」 高 26pt，宽 160pt
  └── Spacer flex-1
  └── 右侧按钮组（间距 6pt）:
        [新建命令集]: Button/Bordered 高 24pt  11pt SF Pro Regular
        [删除命令集]: Button/Bordered 高 24pt  11pt SF Pro Regular  Status/Error（Destructive 变体）
```

### 09-E：内容区（ContentArea）双栏布局

```
尺寸: 560 × flex-1（最小 280pt）
布局: 水平 Auto Layout，间距 0

├── CommandList   180 × 100%   ← 左侧命令列表
├── PaneDivider    1pt × 100%  Border/Faint（静态分割线，不可拖拽）
└── EditPanel     flex-1 × 100% ← 右侧编辑面板
```

#### 左侧命令列表（CommandList）

```
尺寸: 180 × flex-1
背景: Surface/Window
布局: Vertical Auto Layout，间距 0

命令行（CommandRow）:
  尺寸: 180 × 36pt
  内边距: 左 12pt 右 8pt，垂直居中
  布局（水平，间距 6pt）:
    ├── DragHandle: SF Symbol「line.3.horizontal」10pt  Text/Disabled
    │    Default: opacity 0，Row Hover: opacity 1
    ├── 命令名文字: flex-1  12pt SF Pro Regular  Text/Primary（选中）/ Text/Secondary（未选）
    │    超出 ellipsis
    └── （Row Selected 状态：右侧 2pt Accent 指示线，背景 Accent/Glow）

  背景:
    Default:  Surface/Window
    Hover:    Surface/Toolbar
    Selected: Accent/Glow

分割线（CommandDivider）:
  SF Symbol「line.horizontal.3.decrease.circle.fill」→ 用于视觉分组
  实际实现: 高 1pt  背景 Border/Faint  左右各 8pt 缩进  上下各 4pt 间距

底部 FooterArea（固定于列表底部）:
  尺寸: 180 × 36pt
  上边框: 1pt Border/Faint
  背景: Surface/Panel

  [+ 新建命令] 按钮:
    宽度: 160pt（left/right 10pt），高 28pt，圆角 5pt
    背景: Accent/Dim
    边框: Accent/Border 1pt 虚线（dasharray: 3 2）
    文字: 「＋ 新建命令」  11pt SF Pro Medium  Accent/Default
    Hover: 背景 rgba(Accent,0.22)，边框实线
```

#### 右侧编辑面板（EditPanel）

```
尺寸: flex-1（约 378pt）× flex-1
背景: Surface/Elevated
内边距: 14pt

布局: Vertical Auto Layout，间距 12pt

① 名称 FormGroup:
    Label: 「名称」  10pt SF Pro Medium  Text/Tertiary  Uppercase  LS 0.04em
    Input: 高 28pt，满宽
    示例值: 「查看系统状态」

② 命令内容 FormGroup:
    Label: 「命令内容」（右侧附小标签: 「支持多行，按序发送」  9pt  Text/Disabled）
    CodeEditor 区域:
      尺寸: 满宽 × 100pt（最小 60pt，可调整）
      背景: Terminal/Background
      边框: Border/Default  1pt  圆角 5pt
      内边距: 8pt
      字体: 11pt SF Mono  Terminal/White  行高 18pt

      行号列（左侧 24pt）:
        背景: Surface/Overlay（比编辑区略亮）
        右边框: 1pt Border/Faint
        文字: 10pt SF Mono  Text/Disabled  右对齐

      代码内容区（flex-1）:
        光标: I-Beam（文字输入区）

③ 选项行（水平 Auto Layout，间距 16pt）:
    Toggle + Label「☑ 末尾自动追加回车」  12pt  Text/Secondary
    Toggle + Label「☐ 逐行发送」          12pt  Text/Secondary

④ 快捷键 FormGroup:
    Label: 「快捷键（可选）」  10pt  Text/Tertiary  Uppercase
    KeyRecorder 控件（见组件规格）

⑤ 底部按钮行（水平，右对齐，间距 8pt，固定在面板底部）:
    [删除] 按钮: Button/Borderless  Destructive 变体  11pt  Status/Error
    Spacer flex-1
    [保存] 按钮: Button/Bordered/Prominent 高 28pt

─── 空状态（未选中任何命令）: ───────────────────────────────────
  居中显示:
    图标: SF Symbol「text.cursor」36pt  Text/Disabled  opacity 0.4
    文字: 「选择左侧命令进行编辑」  12pt  Text/Disabled
    间距: 图标与文字间 10pt
```

### 09-F：KeyRecorder 快捷键录入控件

```
尺寸: 满宽 × 28pt
背景: Surface/Input
边框: Border/Default  1pt  圆角 5pt
内边距: 左右 10pt

内容（未录入态）:
  占位符: 「点击后按下快捷键组合…」  11pt SF Pro Regular  Text/Disabled

内容（已录入态，如 ⌘⇧1）:
  Key Badges（水平排列，间距 4pt）:
    每个按键: 背景 Surface/Elevated  边框 Border/Subtle  圆角 4pt
              内边距 4pt 7pt  11pt SF Mono  Text/Primary
  右侧删除按钮: SF Symbol「xmark.circle.fill」  14pt  Text/Disabled  Hover: Text/Secondary

录入状态（聚焦时）:
  边框: Accent/Border  2pt
  聚焦环: 3pt Accent/Default 透明度 50%
  内容: 「正在录制，请按下快捷键…」  Text/Tertiary  italic

⚠️ Figma 标注: 此控件需自定义实现，无原生 SwiftUI 对应组件
```
