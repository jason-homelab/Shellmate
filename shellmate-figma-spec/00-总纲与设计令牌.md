## 一、设计语言概述

### 1.1 Liquid Glass（液态玻璃）核心理念

ShellMate v2.0 采用「**Liquid Glass**」设计语言——将玻璃拟态（Glassmorphism）的通透感、拟物化（Skeuomorphism）的质感与现代极简主义融合，在专业 SSH 工具中创造兼具功能性和审美深度的视觉体验。

**三大视觉支柱：**

```
① 通透感（Translucency）
   ├── 系统 vibrancy 材质（.ultraThinMaterial）
   ├── 毛玻璃覆层叠加（rgba 白色透明度分层）
   └── 光折射渐变边框（顶部高光 → 底部阴影）

② 发光感（Luminosity）
   ├── 状态点多层光晕（漫射 + 核心 + 高光球面）
   ├── 强调色蓝色发光（accentGlow: #2C7EF8 @ 20-38%）
   └── 强调按钮、选中项的彩色外发光 shadow

③ 深度感（Depth）
   ├── 多层分离阴影（黑色 @52% radius:32pt）
   ├── 深空蓝黑底色（#07090F）衬托浮层
   └── 玻璃表面高光点（拟物球面渲染）
```

### 1.2 三条核心铁律（继承自 v1.0）

**原则 A：语义优先于字面值**
所有颜色使用有语义含义的令牌名，确保深色/浅色模式自动适配。

**原则 B：系统控件优先于自定义**
macOS 原生控件直接使用，SSH 工具差异化在功能布局，不在重新设计原子组件。

**原则 C：强调色永远不硬编码**
主按钮、选中状态均标注 `[跟随 controlAccentColor]`，Figma 中用 `#2C7EF8` 作设计参考值。

## 三、圆角系统 v2.0

```
Radius/XSmall  →   5pt   极小：状态徽章、标签点
Radius/Small   →   8pt   小型：按钮、输入框、Tab 项
Radius/Medium  →  12pt   中型：卡片、列表项、下拉项   ← 主力圆角
Radius/Large   →  16pt   大型：面板容器、弹窗内区块
Radius/XLarge  →  20pt   超大：Sheet 弹窗、主面板
Radius/Panel   →  24pt   面板级：最大容器
Radius/Full    → 999pt   圆形：头像、开关轨道
```

**圆角哲学：**
- 更大的圆角比例（8-24pt）比旧版（4-12pt）增大约 50%
- 连续曲线使用 `style: .continuous`（Figma 中对应"smooth corners"选项）
- 所有圆角矩形必须勾选 Figma 的 **Corner Smoothing: Squircle**

## 四、阴影系统 v2.0（分层阴影）

### 4.1 基础阴影层级

每个浮层元素使用**两层叠加阴影**：

```
Shadow/Small（按钮级）:
  Layer 1: 0 2pt 6pt rgba(0,0,0,0.28)
  Layer 2: 0 0 12pt rgba(0,0,0,0.15)  ← 漫射光晕

Shadow/Medium（卡片级）:
  Layer 1: 0 7pt 16pt rgba(0,0,0,0.40)  ← 主阴影
  Layer 2: 0 2pt 6pt rgba(0,0,0,0.25)   ← 近端阴影

Shadow/Large（弹窗级）:
  Layer 1: 0 14pt 32pt rgba(0,0,0,0.52)
  Layer 2: 0 4pt 12pt rgba(0,0,0,0.35)

Shadow/XLarge（模态级）:
  Layer 1: 0 24pt 56pt rgba(0,0,0,0.65)
  Layer 2: 0 8pt 20pt rgba(0,0,0,0.45)
```

### 4.2 彩色光晕阴影（精髓）

```
Glow/Accent（强调元素激活态）:
  0 0 18pt rgba(44,126,248,0.22)   ← accentGlow

Glow/Accent/Strong（主按钮聚焦）:
  0 0 28pt rgba(44,126,248,0.38)   ← accentGlowStrong

Glow/Connected（已连接状态点）:
  0 0 8pt rgba(52,211,153,0.32)

Glow/Connecting（连接中状态点）:
  0 0 8pt rgba(251,191,36,0.32)

Glow/Error（错误状态点）:
  0 0 8pt rgba(251,113,133,0.32)
```

## 五、发光状态指示灯规范

### 5.1 GlowingStatusDot 结构（拟物球感）

```
整体容器: size × 2.8 (视觉空间)

Layer 1（外层漫射光晕）:
  形状: Circle，size × 2.8
  填充: statusColor @ 20%
  模糊: size × 0.9
  ← 营造光线弥散到空气中的效果

Layer 2（中层光晕）:
  形状: Circle，size × 1.7
  填充: statusColor @ 38%
  模糊: size × 0.35
  ← 更集中的光晕核心

Layer 3（实心核心点）:
  形状: Circle，size（默认 7pt）
  填充: statusColor 100%
  ← 最亮的中心

Layer 4（高光球面点）:
  形状: Circle，size
  填充: RadialGradient
    中心 (0.32, 0.28): white @ 60%
    边缘: clear
  ← 拟物玻璃球的顶部高光，模拟三维光照
```

**颜色映射：**
```
.connected    → #34D399（翠绿）+ 绿色光晕
.connecting   → #FBBF24（琥珀）+ 黄色光晕 + 脉冲动画
.error        → #FB7185（玫瑰红）+ 红色光晕
.offline      → #475569（冷灰蓝）无光晕
```

### 5.2 动画规范（连接中）

```
连接中状态点动画:
  效果: opacity 0.5 ↔ 1.0 循环
  周期: 1.2s
  曲线: ease-in-out
  Reduce Motion 降级: 固定 opacity 0.85，取消动画
```

## 六、按钮设计规范 v2.0

### 6.1 主按钮（PrimaryButtonStyle）

```
外形: 圆角矩形，Radius/Small (8pt)
背景: 渐变 #3D8EFF → #1E5CD0（左上 → 右下）
      + 顶部白色高光层（rgba(255,255,255,0.22) → clear，top → center）
      + glassBorder 线宽 0.5pt（rgba(255,255,255,0.18)）
文字: 白色，12pt SF Pro Medium
阴影: accentGlow（0 0 12pt rgba(44,126,248,0.20)）

按下态:
  透明度: 82%
  缩放: scale 0.975
  阴影收缩: radius 6pt（减少）

禁用态:
  背景: surfaceCard（无渐变）
  透明度: 40%
  无阴影
```

### 6.2 次要按钮（SecondaryButtonStyle）

```
外形: 圆角矩形，Radius/Small (8pt)
背景: glassLight（rgba(255,255,255,0.06)）
边框: glassBorder 渐变，线宽 0.75pt
文字: textPrimary，12pt SF Pro Medium

按下态:
  背景切换为 glassPress（rgba(255,255,255,0.12)）
  缩放: scale 0.975
```

### 6.3 工具栏图标按钮（ToolbarIconButtonStyle）

```
容器: 26×26pt，Radius/XSmall (5pt)
图标: 默认 textSecondary；激活态 accentPrimary
背景:
  默认: transparent
  悬停: glassHover（rgba(255,255,255,0.08)）
  激活: accentGlow（rgba(44,126,248,0.20)）
  按下: glassPress（rgba(255,255,255,0.12)）

缩放: 按下时 scale 0.90（比常规按钮更大的收缩感）
```

## 七、输入框规范 v2.0（玻璃输入）

```
外形: 高度 30pt，Radius/Small (8pt)
背景: surfaceInput（#0A0E1A）+ glassUltraLight 覆层
边框（默认）: glassBorder 渐变，线宽 0.75pt

聚焦态:
  边框: accentPrimary→accentSecondary 渐变，线宽 1.0pt
  外发光: accentPrimary @ 25%，blur 2pt，宽度 3pt
  ← 蓝色呼吸光晕，区别于传统输入框的「亮边」

错误态:
  边框: statusError @ 70% → statusError @ 40%，线宽 1.0pt
  右侧图标: exclamationmark.circle.fill，statusError
  错误文字: 11pt，statusError

无障碍:
  错误状态通过颜色 + 图标 + 文字三重方式传达
  聚焦环满足 WCAG 2.1 AA（对比度 ≥ 3:1）
```

## 十一、Figma 实现指南

### 11.1 玻璃卡片组件构建步骤

在 Figma 中创建玻璃卡片（对应 SwiftUI `.glassCard()`）：

```
1. 创建 RoundedRectangle，smooth corners，radius 12pt
2. 填充 Layer 1: 颜色 #FFFFFF @4%（glassUltraLight）
3. 填充 Layer 2: 渐变 glassBorder（描边，0.75pt）
4. Effects:
   - Background Blur: 20pt（近似 .ultraThinMaterial）
   - Drop Shadow: 0 7 16 rgba(0,0,0,0.40)（medium 阴影）
5. 在组件上添加标注：
   ⚠️ VIBRANCY ZONE: .ultraThinMaterial
   实际渲染以 Xcode 为准，Figma 为近似效果
```

### 11.2 状态点组件构建

```
1. 最内层 Circle（核心点）: 7pt，实色状态色
2. 中层 Circle（光晕 1）: 12pt，状态色 @38%，blur 2.5pt
3. 外层 Circle（光晕 2）: 20pt，状态色 @20%，blur 7pt
4. 顶层 RadialGradient 高光: 7pt，白@60% center → clear edge
5. 整组居中对齐，外部容器 20pt（光晕充分展开）
```

### 11.3 交付 Handoff 标注模板

每个使用玻璃效果的组件必须标注：

```
【SwiftUI 实现】.glassCard(radius: 12)
【背景材质】.ultraThinMaterial + Color.white.opacity(0.04)
【边框】strokeBorder(glassBorder(), lineWidth: 0.75)
【阴影】Shadow/Medium: 0 7 16 rgba(0,0,0,0.40)
【圆角】.continuous style（Squircle 曲线，非标准圆角）
⚠️ Vibrancy 效果以 Xcode 真实渲染为准
```
