## 一、设计语言概述 v3.0

### 1.1 设计哲学：macOS Native First

ShellMate v3.0 以「**macOS Native Light**」为主调，兼容 Dark Mode 自适应。设计语言回归苹果原生美学：

```
① 原生材质优先（Native Material First）
   ├── 窗口标题栏: NSVisualEffectView / .titleBar material
   ├── 侧边栏: #f5f5f7/95 + backdrop-blur-xl（Light）
   │              #1C1C1E/95 + blur（Dark）
   └── 工具栏/状态栏: 同侧边栏材质，整体统一

② 系统蓝色生态（Apple Blue System）
   ├── 主色: #007AFF（Apple 系统蓝，controlAccentColor）
   ├── 辅色: #5856D6（Apple Indigo，内存/AI 场景）
   └── 状态: 严格使用 Apple HIG 语义色

③ 玻璃感点缀（Selective Glass）
   ├── 仅用于浮层、弹窗、AI 面板等覆层场景
   ├── bg-white/90~95 + backdrop-blur-xl（Light）
   └── bg-black/80 + backdrop-blur-xl（Dark）
```

### 1.2 三条核心铁律

**原则 A：Apple 系统色优先**
主色严格使用 `#007AFF`（`NSColor.controlAccentColor`），禁止使用 `#2C7EF8` 等自定义蓝色替代系统蓝。

**原则 B：Light / Dark 双适配**
所有颜色令牌必须同时提供 Light 和 Dark 值。SwiftUI 实现使用 `adaptive(light:dark:)` 方法。

**原则 C：层级清晰，材质分明**
窗口 < 面板 < 卡片 < 浮层，每层有明确的背景值，不得跳级使用。

## 二、色彩系统 v3.0

### 2.1 原始色板（Primitives）

**Apple 系统语义色（严格跟随 HIG）**

```
Apple Blue        #007AFF   ← controlAccentColor（主强调色）
Apple Indigo      #5856D6   ← 辅助强调（内存、AI 渐变）
Apple Green       #34C759   ← 连接成功状态
Apple Orange      #FF9500   ← 连接中/警告状态
Apple Red         #FF3B30   ← 错误状态
Apple Gray        #8E8E93   ← 中性/离线状态
```

**Light Mode 基础面（来自 Figma 原型）**

```
Surface/Window   #F5F5F7        ← 应用主背景（to-[#e8e8ed] 渐变终点）
Surface/Window2  #E8E8ED        ← 渐变辅色
Surface/Panel    #F5F5F7/95     ← 侧边栏/工具栏背景（半透明）
Surface/Card     #FFFFFF/95     ← 弹窗/面板卡片
Surface/Input    #FFFFFF/80     ← 输入框背景
Border/Primary   #D2D2D7/50    ← 所有分割线/边框
```

**Dark Mode 基础面**

```
Surface/Window   #07090F        ← 深空蓝黑（应用背景）
Surface/Panel    #0C1018        ← 面板/工具栏
Surface/Card     #101520        ← 卡片
Surface/Input    #0A0E1A        ← 输入框
Border/Primary   rgba(255,255,255,0.08)  ← 玻璃边框
```

**文字色**

```
Light Mode:
  Text/Primary     #1D1D1F   ← 主文字（Apple 标准近黑）
  Text/Secondary   #86868B   ← 副文字（Apple 标准中灰）
  Text/Tertiary    #AEAEB2   ← 弱文字

Dark Mode:
  Text/Primary     #EDF0FF   ← 微蓝调白
  Text/Secondary   #8892AA   ← 冷灰蓝
  Text/Tertiary    #525D78   ← 深冷灰
```

**状态色（双模式统一值）**

```
Connected:   Light #34C759  /  Dark #34D399   ← 已连接（绿）
Connecting:  Light #FF9500  /  Dark #FBBF24   ← 连接中（琥珀）
Error:       Light #FF3B30  /  Dark #FB7185   ← 错误（红）
Offline:     Light #8E8E93  /  Dark #475569   ← 离线（灰）
```

### 2.3 交互状态色

```
【Light Mode】
Hover:     rgba(0,0,0,0.05)   → bg-black/5
Selected:  #007AFF（实色背景）  → 文字反白
Press:     rgba(0,0,0,0.10)   → bg-black/10

【Dark Mode】
Hover:     rgba(255,255,255,0.08)   → glassHover
Selected:  accentPrimary @ 14%      → glassSelected
Press:     rgba(255,255,255,0.12)   → glassPress
```

## 三、圆角系统 v3.0

```
Radius/XSmall  →   4pt   标签/徽章（rounded-full 对应 px-2 类）
Radius/Small   →   8pt   按钮、输入框、列表项（rounded-lg）
Radius/Medium  →  10pt   卡片容器（rounded-xl）
Radius/Large   →  12pt   面板侧栏（rounded-xl 偏大）
Radius/XLarge  →  16pt   弹窗内大模块（rounded-2xl）
Radius/Panel   →  16pt   弹窗容器（rounded-2xl）
Radius/Full    → 999pt   圆形按钮、徽章 Pill（rounded-full）
```

> **关键规则：** 所有 `RoundedRectangle` 必须使用 `style: .continuous`（Squircle 曲线）。
> 圆形按钮使用 `.clipShape(Circle())` 而非 `.cornerRadius(n)`。

## 六、字体规范 v3.0

```
系统字体栈: SF Pro Text（正文）/ SF Pro Display（标题）/ SF Mono（代码）

titleLarge:    SF Pro Display  18pt  semibold   ← 弹窗标题
titleMedium:   SF Pro Text     15pt  semibold   ← 面板标题
titleSmall:    SF Pro Text     13pt  semibold   ← 区块标题

labelLarge:    SF Pro Text     13pt  medium     ← 主要标签
labelMedium:   SF Pro Text     12pt  medium     ← 次级标签
labelSmall:    SF Pro Text     11pt  medium     ← 徽章/状态

bodyLarge:     SF Pro Text     13pt  regular    ← 主正文
bodyMedium:    SF Pro Text     12pt  regular    ← 副正文
bodySmall:     SF Pro Text     11pt  regular    ← 说明文字

codeRegular:   SF Mono         13pt  regular    ← 终端/代码
codeSmall:     SF Mono         12pt  regular    ← 主机地址/路径
codeTiny:      SF Mono         11pt  regular    ← 内嵌代码片段
```

**主机地址强制等宽：**
侧边栏 `user@host`、状态栏路径，一律使用 `codeSmall`（SF Mono 12pt），保证对齐专业感。
