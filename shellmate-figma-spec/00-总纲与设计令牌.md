## 一、核心设计原则

### 1.1 对齐 macOS HIG 的三条铁律

在所有设计决策中，以下三条原则优先于美学考量：

**原则 A：语义优先于字面值**
所有颜色、字体必须使用有语义含义的名称（`Text/Primary` 而非 `#EEEDF5`），确保深色/浅色模式一键切换时所有界面自动适配。

**原则 B：系统控件优先于自定义**
凡是 macOS 提供了原生控件的地方（按钮、输入框、复选框、下拉菜单、Alert），设计稿必须直接使用 Apple Design Resources 中的官方组件，不得自行设计替代方案。SSH 工具的差异化在于功能和布局，而非重新设计按钮。

**原则 C：强调色永远不硬编码**
所有需要跟随用户强调色偏好的元素（主要按钮、选中状态、聚焦环、进度条、激活的切换开关），在 Figma 中统一使用 `Accent/Default` 颜色变量。最终渲染时由 `NSColor.controlAccentColor` 决定实际颜色（蓝/紫/橙/红/绿等 9 种选项）。

### 1.2 差异化设计的边界

ShellMate 需要自定义的区域：
- 侧边栏会话列表的行布局（状态点 + 名称 + 标签徽章）
- 顶部水平标签页（macOS 无原生横向标签）
- 终端内容区域（字体、配色主题）
- 状态栏的信息密度布局

这些区域在自定义时仍需遵循 HIG 的间距、字号、颜色使用规范。

### 3.2 Vibrancy 的 Figma 表示方法

macOS 的 Vibrancy（玻璃磨砂）效果在 Figma 中无法精确模拟，采用约定的替代方案：

**侧边栏（Dark Mode）：**
- Fill: `#111115` 不透明度 85%
- 上加一层 Blur Effect: 30px
- 在标注中写明：`[VIBRANCY] NSVisualEffectView.sidebar`

**侧边栏（Light Mode）：**
- Fill: `#F5F5F5` 不透明度 70%
- 上加一层 Blur Effect: 30px
- 标注同上

**在每个使用 Vibrancy 的组件上，添加专属标注层：**
```
⚠️ VIBRANCY ZONE
此区域在 Figma 中为近似效果
实际渲染：NSVisualEffectView(.sidebar)
开发者无需匹配 Figma 截图，以 Xcode 渲染为准
```

## 六、阴影与层次

### 6.1 Elevation（海拔层次）

macOS 应用通过材质（Material）而非阴影创造层次感。以下是 Figma 中的近似表达：

```
Elevation 0  →  应用背景，无阴影
Elevation 1  →  侧边栏、工具栏（Vibrancy Material）
Elevation 2  →  弹出菜单 Shadow: 0 4px 16px rgba(0,0,0,0.5)
Elevation 3  →  Sheet 弹窗 Shadow: 0 12px 40px rgba(0,0,0,0.65)
Elevation 4  →  Alert 模态 Shadow: 0 20px 60px rgba(0,0,0,0.75)
```

### 6.2 聚焦环

所有可交互元素聚焦（键盘 Tab 选中）时必须显示聚焦环：

```
Focus Ring:
  颜色: Accent/Default 透明度 50%
  宽度: 3pt
  偏移: 2pt（环绕在组件外部）
  样式: 外轮廓（非 border，不占用布局空间）
```

## 八、Figma 协作规范

### 8.1 图层命名规范

```
✅ 正确命名:
  Button/Primary/Default
  Session Row/Connected/Selected
  [Background] Surface/Window
  [Border] Border/Default

❌ 错误命名:
  Rectangle 234
  Group 12
  蓝色按钮
  copy of Button
```

### 8.2 组件约束（Constraints）

```
侧边栏: Left + Top，固定宽度 220pt
终端区域: Left & Right + Top & Bottom（stretch）
SFTP 面板: Right + Top，固定宽度 290pt
标题栏: Left & Right + Top，固定高度 52pt
状态栏: Left & Right + Bottom，固定高度 24pt
弹窗: Center（水平 + 垂直居中于父容器）
```

### 8.3 Auto Layout 规范

所有复合组件必须使用 Auto Layout，禁止使用绝对定位（Figma 中的固定位置）：

```
侧边栏:
  方向: Vertical
  间距: 0pt
  主轴: Top（固定在顶部）

会话行（Session Row）:
  方向: Horizontal
  对齐: Center（垂直居中）
  间距: 8pt
  填充: 6pt 上下，18pt 左，10pt 右

弹窗内容:
  方向: Vertical
  间距: 14pt（表单组之间）
  填充: 18pt 四周
```

### 8.4 Handoff 标注规范

每个组件和界面交付时，必须添加以下标注：

```
【SwiftUI 组件】Button / .borderedProminent
【颜色变量】Accent/Default → controlAccentColor
【字体】UI/Body/Medium → .system(size:12, weight:.medium)
【Vibrancy 区域】⚠️ 此区域使用系统 Material，Figma 近似，以 Xcode 为准
【状态说明】以下 3 个状态需实现：Default / Hover / Pressed
【动画】连接中状态：scale 0.8↔1.0，1.2s，ease-in-out，repeat forever
```
