# 03 — 动效与交互规范 v3.0

> **文档版本：** v3.0（对齐 Figma Make Shell 原型动效）
> **更新日期：** 2026-03-30
> **重要：** 所有动效必须实现 `Reduce Motion` 无障碍模式降级方案

---

## 一、过渡时长标准

```
duration-100   → 100ms  极快（tooltip 出现）
duration-150   → 150ms  快速（状态色切换）
duration-200   → 200ms  ★ 标准（大部分 hover/press 过渡）
duration-300   → 300ms  适中（面板展开/折叠）
duration-500   → 500ms  慢速（进度条、数值更新）
```

**SwiftUI 对应值：**
```swift
Animation.fast     → .easeInOut(duration: 0.2)
Animation.medium   → .easeInOut(duration: 0.3)
Animation.spring   → .spring(response: 0.35, dampingFraction: 0.75)
```

## 二、按钮交互动效

### 2.1 工具栏图标按钮（h-7 w-7）

```
hover 进入: bg-black/5 出现，duration-200
hover 离开: bg → transparent，duration-200
按下:       scale 0.95，duration-100
松开:       scale 1.0，duration-150

SwiftUI:
  .buttonStyle(.plain)
  .scaleEffect(isPressed ? 0.95 : 1.0)
  .animation(.easeInOut(duration: 0.1), value: isPressed)
```

### 2.2 主要按钮（Create / Save / 蓝色按钮）

```
hover: bg 从 #007aff → #0051d5，duration-200
       shadow-lg → shadow-xl，duration-200
按下: scale 0.975，duration-100
disabled: opacity-40（无动画）
```

### 2.3 文字按钮（Connect / Disconnect / Cancel）

```
hover: bg transparent → bg-black/5，duration-200
按下: bg-black/10，duration-100
```

## 六、面板展开/折叠动效（AI/SFTP 面板）

```
AI 助手面板（左侧）:
  展开: width 0 → 400pt，duration-300，ease-in-out
  折叠: width 400pt → 0，duration-250，ease-in-out

        .transition(.move(edge: .trailing)) // SFTP 右侧
```

## 七、脚本自动化浮层动效

```
遮罩出现: bg-black/30 渐入，duration-200
容器进入:
  起始: scale 0.96，opacity 0
  终止: scale 1.0，opacity 1
  duration: 300ms，spring(response: 0.35, dampingFraction: 0.75)

关闭:
  容器: scale 1.0 → 0.96，opacity 1 → 0，duration-200
  遮罩: 同步渐出，duration-200
```

## 八、弹窗（Dialog）出现/消失动效

```
遮罩: opacity 0 → 1，duration-200
Dialog 容器:
  进入: scale 0.95，opacity 0 → scale 1.0，opacity 1
        duration-300，spring(response: 0.4, dampingFraction: 0.8)
消失:
  scale 1.0 → 0.95，opacity 1 → 0，duration-200 ease-in
```

## 九、状态栏资源数值更新动效

```
数值更新（CPU/内存/网络）:
  更新间隔: 2000ms
  值变化: 无特殊动画，直接更新（避免频繁动画影响性能）

进度条（内存使用率）:
  width 变化: transition-all duration-500
  颜色变化:   duration-300

状态点（连接中 animate-pulse）:
  opacity: 0.5 ↔ 1.0，循环
  周期: 1.5s，ease-in-out
  Reduce Motion 降级: 固定 opacity-85，取消动画
```

## 十二、Reduce Motion 降级规则

| 动效 | 正常 | Reduce Motion |
|------|------|---------------|
| 弹窗进入 | scale + opacity | 仅 opacity |
| 面板展开 | width + opacity | 直接显示/隐藏 |
| 列表项 hover | bg 渐变 | 直接切换 bg |
| 状态点脉冲 | animate-pulse | 固定 opacity |
| 折叠旋转 | rotate 渐变 | 直接切换 |
| 消息气泡进入 | scale + opacity | 仅 opacity |

```swift
@Environment(\.accessibilityReduceMotion) var reduceMotion
// 使用 reduceMotion 条件替换 spring → easeInOut(duration: 0.1)
```
