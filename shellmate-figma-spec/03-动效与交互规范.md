# ShellMate — 动效与交互规范

> **文档版本：** v1.0
> **创建日期：** 2026-03-18
> **重要：** 所有动效必须实现 `Reduce Motion`（减弱运动）无障碍模式的降级方案

---

## 一、动效设计原则

### 1.1 macOS 动效哲学

macOS 的动效遵循「有目的的运动」原则：

- **功能性**：每个动画都应传达意义（状态变化、元素关系、层级关系）
- **克制**：动画不是装饰，短促有力优于华丽拖拉
- **一致**：使用系统级曲线和时长，与 macOS 其他应用保持一致感
- **尊重用户**：提供「减弱运动」选项，对光敏感用户友好

### 1.2 时长参考（来自 Apple HIG）

```
即时反馈（按下状态）:   100ms
微型过渡（颜色、透明度）: 150ms
标准过渡（元素出现/消失）: 200–250ms
大型过渡（面板展开/折叠）: 250–300ms
Sheet 弹出:            300ms
Alert 弹出:            200ms
禁止使用超过 500ms 的动画（除非用户主动触发的展开动画）
```

## 二、各组件动效规范

### 2.1 侧边栏 Sidebar

**分组折叠/展开：**
```
触发: 点击分组标题
持续: 250ms
曲线: ease-in-out
效果:
  - 箭头旋转 0° → -90°（折叠）/ -90° → 0°（展开）
  - 内容区域高度 height auto → 0（折叠），带 overflow: hidden

Reduce Motion 降级:
  - 取消高度动画，直接显示/隐藏
  - 箭头旋转保留（不是运动，是状态图标）
```

**会话行 Hover：**
```
触发: 鼠标进入
持续: 120ms
曲线: ease-out
效果: 背景色 transparent → Surface/Overlay

Reduce Motion: 无变化（颜色切换可保留）
```

**选中高亮 Active Indicator（左侧蓝线）：**
```
触发: 点击会话
持续: 150ms
曲线: ease-out
效果:
  - 左侧 2pt 指示线 scale(Y): 0 → 1，从中点展开
  - 背景色淡入: transparent → Accent/Glow

Reduce Motion:
  - 指示线直接显示，无缩放动画
  - 背景色直接切换
```

### 2.2 标签页 TabBar

**新建标签页：**
```
触发: 点击 + 按钮或双击会话
持续: 200ms
曲线: ease-out
效果:
  - 新 Tab 从右侧 translateX(20pt) → translateX(0)

  - 直接出现，无滑入
```

**关闭标签页：**
```
触发: 点击 × 按钮
持续: 150ms
曲线: ease-in
效果:
  - Tab 宽度: 当前宽 → 0
  - opacity: 1 → 0
  - 右侧 Tab 向左滑动填补空缺

Reduce Motion:
  - 直接消失，其他 Tab 直接调整位置
```

**激活状态顶部线：**
```
持续: 150ms
效果: 从相邻 Tab 滑入当前位置（跟随点击 Tab 位置）
Reduce Motion: 直接切换位置
```

### 2.3 连接状态指示灯

**连接中（Connecting）- 脉冲动画：**
```
类型: opacity + scale，loop
持续: 1.2s（单次），无限循环
曲线: ease-in-out
关键帧:
  0%:   opacity 1.0, scale 1.0
  50%:  opacity 0.6, scale 0.85
  100%: opacity 1.0, scale 1.0

代码实现（SwiftUI）:
  @State private var pulsing = false
  Circle()
      .scaleEffect(pulsing ? 0.85 : 1.0)
      .opacity(pulsing ? 0.6 : 1.0)
      .animation(.easeInOut(duration: 1.2).repeatForever(autoreverses: true), value: pulsing)
      .onAppear { pulsing = true }

Reduce Motion:
  取消动画，显示静态琥珀色点（无脉冲）
```

**已连接 → 断开：**
```
持续: 300ms
效果:
  - 绿色发光阴影: 淡出
  - 颜色: Status/Connected → Text/Disabled
Reduce Motion: 直接切换颜色
```

**断开 → 已连接（重连成功）：**
```
持续: 400ms
效果:
  - 颜色: Text/Disabled → Status/Connected
  - 发光阴影: scale 0 → 1 的弹入效果（spring）
Reduce Motion: 直接切换颜色
```

### 2.4 弹窗 Modals

**Sheet（新建会话、编辑会话）：**
```
触发: 点击「新建会话」按钮
持续: 300ms
曲线: spring（stiffness: 300, damping: 25）
效果:
  - Sheet 从标题栏下方 translateY(-100%) → translateY(0)
  - 主窗口内容向下推移 scale(0.98) + translateY(20pt)（macOS 标准）
  - 背景模糊: blur(0) → blur(8pt)

SwiftUI 实现: .sheet() 自动处理，无需手动实现

Reduce Motion:
  - Sheet 直接出现，无滑入
  - 背景不模糊
```

**Alert（P0 安全警告）：**
```
触发: 检测到密钥变更
持续: 200ms
曲线: spring（stiffness: 500, damping: 30）
效果:
  - Alert 从 scale(0.9) → scale(1.05) → scale(1.0)（略带弹入感）
  - opacity: 0 → 1
  - 背景模糊加深

SwiftUI 实现: .alert() 自动处理

Reduce Motion:
  - 直接出现，无弹入
```

**Context Menu（右键菜单）：**
```
触发: 右键点击
持续: 100ms
曲线: ease-out
效果:
  - 从鼠标位置展开
  - scale(0.95) → scale(1.0)
  - opacity: 0 → 1

SwiftUI 实现: .contextMenu() 自动处理，系统级动效
```

### 2.6 传输进度条

**进度条填充：**
```
持续: 实时更新（每次数据包到达时更新，约 200ms 缓动）
曲线: ease-out
效果: width 平滑增长（非跳跃更新）

Shimmer 光效:
  持续: 1.6s，无限循环
  效果: 半透明白色光从左到右扫过进度条
  关键帧:
    0%:   translateX(-100%)
    100%: translateX(200%)

Reduce Motion:
  禁用 Shimmer 效果，保留进度宽度更新
```

**传输完成：**
```
持续: 200ms
效果:
  - 进度条颜色: Accent/Default → Status/Connected（绿色）
  - ↑ 箭头 → ✓ 图标，配合 scale(1.3) → scale(1.0) 弹入

Reduce Motion: 直接切换颜色和图标
```

## 三、减弱运动（Reduce Motion）全局方案

在所有动效实现中，必须检测系统「减弱运动」设置：

```swift
// SwiftUI
@Environment(\.accessibilityReduceMotion) var reduceMotion

// 使用示例
.animation(reduceMotion ? nil : .spring(stiffness: 300, damping: 25), value: isVisible)

// 或使用条件帧率
.withAnimation(reduceMotion ? .linear(duration: 0) : .easeOut(duration: 0.25)) {
    // 状态变化
}
```

**Figma 标注方式：**
每个包含动效的组件，在标注中添加：

```
【动效规范】
默认: translateY(-100%) → (0), 300ms, spring
Reduce Motion: 无动画，直接显示
```

## 四、光标样式

当用户鼠标悬停在可交互区域时，光标样式跟随：

| 区域 | 光标 | SwiftUI |
|------|------|---------|
| 普通文字、标签 | 默认箭头 | `.cursor(.default)` |
| 可点击按钮 | 默认箭头（macOS 不用 pointer） | 不变 |
| 可编辑文字区域 | I 形光标 | 自动 |
| 终端内容区 | I 形光标（选择文字）| `TerminalView` 自动处理 |
| 侧边栏拖拽边 | 水平调整 ↔ | `.cursor(.columnResize)` |
| 分屏分割线 | 水平/垂直调整 | `.cursor(.rowResize)` / `.columnResize` |
| 文件拖拽目标 | 复制 + | `.cursor(.dragCopy)` |
