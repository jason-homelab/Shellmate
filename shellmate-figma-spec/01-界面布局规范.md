# 01 — 界面布局规范 v3.0

> **文档版本：** v3.0（对齐 Figma Make Shell 原型）
> **更新日期：** 2026-03-30

---

## 一、主窗口整体层级

```
┌──────────────────────────────────────────────────────┐
│  TitleBar  [h=40pt]  交通灯 + 居中标题                 │
├──────────────────────────────────────────────────────┤
│  Toolbar   [h=48pt]  工具栏（Connect/工具图标/设置）    │
├────────────┬─────────────────────────────────────────┤
│  Sidebar   │  Terminal Area                           │
│  [w=256pt] │    TabBar [h=40pt]                       │
│            │    Terminal Content（flex-1）             │
│            │    (可选) AI 面板 [w=400pt] 左侧          │
│            │    (可选) SFTP 面板 [w=500pt] 右侧        │
├────────────┴─────────────────────────────────────────┤
│  StatusBar [h=32pt]  连接信息 + 资源监控               │
└──────────────────────────────────────────────────────┘
```

### 1.1 各区域尺寸

| 区域 | 高度/宽度 | 背景材质（Light） | 说明 |
|------|---------|-----------------|------|
| TitleBar | h=40pt | `NSVisualEffectView .titleBar` | macOS 原生 |
| Toolbar | h=48pt | `#f5f5f7/80 + blur-2xl` | 工具按钮行 |
| Sidebar | w=256pt | `#f5f5f7/95 + blur-xl` | 最小 180pt，最大 320pt |
| TabBar | h=40pt | `#f5f5f7/80 + blur-xl` | 多会话标签 |
| StatusBar | h=32pt | `#f5f5f7/90 + blur-2xl` | 连接 + 资源监控 |
| AI 面板 | w=400pt | `#FFFFFF/90 + blur-xl` | 左侧可折叠 |
| SFTP 面板 | w=500pt | `#FFFFFF/90 + blur-xl` | 右侧可折叠 |

## 三、Toolbar（工具栏）

```
┌─────────────────────────────────────────────────────────┐
│ [Connect][Disconnect] | [✦][</>][↔][📄] ··· [会话名]··· [📦][🔍][ℹ] | [⚙] │
└─────────────────────────────────────────────────────────┘
高度: 48pt

边框: border-b #d2d2d7/50
内边距: px-4
间距: gap-3
```

### 3.1 左侧操作区

| 顺序 | 元素 | 类型 | 图标 | 禁用条件 |
|------|------|------|------|----------|
| 1 | Connect | 文字按钮 | `monitor` | 无 |
| 2 | Disconnect | 文字按钮 | — | 无活动会话 |
| — | 分割线 | Separator | — | — |
| 3 | AI 助手 | 图标按钮 | `sparkles` | 无活动会话 |
| 4 | 脚本自动化 | 图标按钮 | `code.slash` | 无 |
| 5 | 文件传输(SFTP) | 图标按钮 | `folder.badge.gearshape` | 无活动会话 |
| 6 | 分屏 | 图标按钮 | `rectangle.split.2x1` | 无 |
| 7 | 日志查看 | 图标按钮 | `doc.text` | 无 |

### 3.2 中央会话 Pill（有活动会话时显示）

```
容器: bg-black/5 px-3 py-1 rounded-full
文字: 12pt SF Pro medium, #1d1d1f
内容: 当前活动会话名
```

### 3.3 右侧工具区

| 图标 | 功能 |
|------|------|
| `square.and.arrow.up.on.square` | 导入/导出 |
| `magnifyingglass` | 全局搜索 |
| `info.circle` | 关于/帮助 |
| — 分割线 — | — |
| `gearshape` | 设置 |

### 3.4 按钮样式规范

```

  h-7 px-3 rounded-lg（8pt）
  背景: transparent  hover: bg-black/5
  文字: 12pt SF Pro medium, #1d1d1f
  transition: all duration-200
  disabled: opacity-40

  h-7 w-7 rounded-lg（8pt）
  背景: transparent  hover: bg-black/5
  图标色: #1d1d1f
  图标尺寸: h-3.5 w-3.5
  transition: all duration-200
  disabled: opacity-40

Separator: h-5 mx-1 #d2d2d7/50 orientation-vertical
```

### 4.2 会话行（Session Row）

```

```

## 七、StatusBar（状态栏）

```
┌────────────────────────────────────────────────────────────┐
│ ● Prod Server · admin@prod.com │ CPU 45% [▉▊▇▇▇] │ RAM 4.2/16GB [░░░] │ Disk │ ↓↑ │   SSH :22 │
└────────────────────────────────────────────────────────────┘
高度: 32pt（h-8）
背景: #f5f5f7/90 + backdrop-blur-2xl
边框: border-t #d2d2d7/50
内边距: px-4
间距: gap-4
font-size: text-xs（12pt）
```

### 7.1 连接状态区（左）

```
已连接:
  ● w-2 h-2 rounded-full bg-[#34c759] animate-pulse
  会话名: font-medium #1d1d1f
  分隔符: • #86868b
  地址: SF Mono #86868b（user@host 格式）

未连接:
  WifiOff icon h-3 w-3 #86868b
  "未连接" text-xs #86868b
```

### 7.2 资源监控芯片（中，仅已连接显示）

每个芯片结构：`分割线 + 图标容器 + 标签 + 值 + (可选)图表`

```
CPU 芯片:
  图标: cpu, bg-[#007aff]/10, color-[#007aff]
  值颜色: <50% → #34c759 | <80% → #ff9500 | ≥80% → #ff3b30
  附: 8根微型柱状图（w-0.5 rounded-full opacity-60）

内存芯片:
  图标: memorychip, bg-[#5856d6]/10, color-[#5856d6]
  值颜色: 按百分比（同 CPU）
  附: w-12 h-1.5 bg-black/5 rounded-full 进度条

磁盘芯片:
  图标: externaldrive, bg-[#ff9500]/10, color-[#ff9500]
  值颜色: 固定 #1d1d1f

网络芯片:
  图标: wifi, bg-[#34c759]/10, color-[#34c759]
  ↓ 下行: #34c759  ↑ 上行: #007aff
  格式: x.x MB/s 或 xxx KB/s
```

### 7.3 右侧（仅已连接显示）

```
Activity icon h-3 w-3 #86868b
"SSH Port {port}" text-xs #86868b
```

  背景: #FFFFFF/95 + backdrop-blur-2xl

  [保存] #007aff 背景，white 文字
         shadow-lg shadow-[#007aff]/30
         rounded-lg，disabled: opacity-40

## 九、设置面板（Settings）

```
Dialog:
  max-w: 600pt
  max-h: 80vh overflow-y-auto
  背景: #FFFFFF/95 + backdrop-blur-2xl
  边框: #d2d2d7/50
  阴影: shadow-2xl
  圆角: rounded-2xl

Tabs（3个）: 通用 | 外观 | 终端
  TabsList: grid-cols-3 bg-black/5 rounded-xl p-1
  TabsTrigger: rounded-lg
               active: bg-white shadow-sm
               transition: all duration-200

通用 Tab: 语言/自动连接/关闭确认/日志/默认协议
外观 Tab: 主题(Light/Dark/System)/字体大小/侧边栏显示
终端 Tab: 配色方案/字体/光标样式/滚动缓冲/响铃/选中复制
```
