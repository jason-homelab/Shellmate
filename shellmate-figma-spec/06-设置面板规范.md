## 一、设置面板整体框架

ShellMate 设置面板采用**弹窗（Dialog）+ 左侧导航列表**的双栏布局，
同时保留 Figma Make 原型中的**弹窗内 Tabs** 作为次级分组方式。

### 1.1 Dialog 容器

```
尺寸: max-w-600pt，max-h-80vh，overflow-y-auto
背景: #FFFFFF/95 + backdrop-blur-2xl
边框: border #d2d2d7/50
阴影: shadow-2xl
圆角: rounded-2xl（16pt）

Header:
  标题: "设置"  18pt SF Pro medium, #1d1d1f
  副标题: "自定义 ShellMate 的外观与行为" 14pt #86868b
```

### 1.2 Tabs 导航栏

```
TabsList:
  布局: grid-cols-3（或更多）
  背景: bg-black/5 + backdrop-blur-sm
  圆角: rounded-xl（12pt）
  内边距: p-1（4pt）

TabsTrigger:
  圆角: rounded-lg（8pt）
  active: bg-white + shadow-sm + transition
  文字: 12pt SF Pro medium
  颜色: #1d1d1f（active）/ #86868b（inactive）
  过渡: all duration-200
```

## 五、AI 助手设置（AI Assistant）

> 对应 `AISettingsView.swift`，此处给出 Figma 规范对齐版

### 5.1 启用开关区

```
HStack（justify-between）:
  [左] VStack:
    Label "AI 助手" + sparkles 图标  13pt medium
    说明文字: "在终端工具栏启用 AI 辅助功能"  11pt #86868b
  Toggle: Switch
```

### 5.2 AI 提供商选择

```
标题: "AI 提供商"  sectionHeader 样式
提供商卡片列表（VStack, spacing: 6pt）:
  每张卡片（providerRow）:
    HStack（p-sm, glassMedium 背景, cornerRadiusSmall）:
      [选中圆钮]: Circle 10pt
        选中: accentPrimary fill + border
        未选中: clear fill + borderPrimary border
      VStack:
        displayName  13pt medium textPrimary
        描述文字     11pt textTertiary
      Spacer
      [无需 API Key 徽章]（仅 Ollama）:
        text-xs font-medium statusConnected
        bg statusConnected/12%
        clipShape RoundedRectangle cornerRadiusXSmall continuous

    选中态背景: accentPrimary/8%
    选中边框: accentPrimary/30% 1pt
    未选中背景: glassMedium
    未选中边框: glassBorderSide 0.5pt
```

### 5.3 API Key 输入区（needsAPIKey 时显示）

```
标题: "API Key"  sectionHeader 样式
HStack:
  [输入框] SecureField / TextField（showAPIKey 切换）
    style: textFieldStyle plain, codeSmall 字体
    padding: sm, bg: surfaceInput
    圆角: cornerRadiusSmall
    边框: borderPrimary 0.5pt
  [显示/隐藏] eye / eye.slash 图标按钮
  [保存] Button:
    背景: accentPrimary, white 文字
    px-md py-xs rounded cornerRadiusSmall

保存结果提示（2秒后消失）:
  成功: checkmark.circle.fill + "API Key 已安全存入 Keychain"  statusConnected
  空值: xmark.circle.fill + "API Key 为空，已清除"  textTertiary

获取链接提示: 11pt textTertiary
  Claude:  "在 console.anthropic.com 获取 API Key"
  OpenAI:  "在 platform.openai.com/api-keys 获取 API Key"
```

### 5.4 Ollama 服务地址（仅 ollama 时显示）

```
标题: "Ollama 服务地址"  sectionHeader 样式
TextField: http://localhost:11434
  style: codeSmall, surfaceInput 背景
说明: "请确保 Ollama 已启动（ollama serve）" 11pt textTertiary
```

### 5.5 模型选择

```
标题: "模型选择"  sectionHeader 样式
Picker: .segmented 样式，绑定 store.modelId
  选项来自 store.provider.models
```

### 5.6 功能开关

```
标题: "功能开关"  sectionHeader 样式

featureToggle 组件模板（HStack）:
  图标: 14pt accentPrimary，frame w-20
  VStack:
    title  13pt medium textPrimary
    subtitle  11pt textTertiary
  Spacer
  Toggle .switch

"错误侦探": exclamationmark.triangle icon + $store.errorDetectiveEnabled
```

## 六、安全设置（Security）

### 6.1 主密码区

```
状态卡片（mainPasswordCard）:
  HStack（p-md, glassMedium 背景, cornerRadiusMedium rounded）:
    图标: lock.shield.fill 16pt accentPrimary
    VStack:
      标题: "主密码保护"  13pt medium
      副标题: "已设置 / 未设置"  11pt textTertiary
    Spacer
    [设置/修改] Button accentPrimary / [关闭] Button statusError

输入区（设置状态时显示）:
  SecureField "新主密码"
  SecureField "确认密码"
  [确认] Button accentPrimary

提示：密码强度指示条（弱/中/强）
```

### 6.2 Keychain 访问设置

```
Toggle:
  "会话密码存入 Keychain"
  "私钥 Passphrase 存入 Keychain"
  "主机指纹存入 Keychain"
```

### 6.3 已知主机管理

```
列表: host 域名 + 算法 + 指纹前缀
操作: [清除全部] Button statusError
```

## 七、iCloud 同步设置（CloudSync）

```
同步开关:
  Toggle: "启用 iCloud Drive 同步"
  Desc: "会话配置在您的 Apple 设备间自动同步（密码不同步）"

同步状态卡片:
  bg-glassMedium rounded-cornerRadiusMedium p-md
  状态行: statusDot + 状态文字
    synced: "已同步"  statusConnected
    syncing: "同步中..."  statusConnecting + ProgressView
    conflict: "存在冲突"  statusConnecting
    failed: "同步失败"  statusError
    disabled: "同步已关闭"  textTertiary

  [上次同步时间] 11pt textTertiary
  [立即同步] Button（enabled when synced/failed）

冲突处理（conflict 状态时）:
  [保留本地] Button  [使用云端] Button
```
