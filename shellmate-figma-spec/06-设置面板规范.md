```
⚠️ 重要：macOS 原生 Slider 组件，优先使用系统控件

    尺寸: 18×18pt  圆形
    背景: #FFFFFF  阴影: 0 1pt 4pt rgba(0,0,0,0.3)

  Default: 见上
  Disabled: Thumb 颜色 Text/Disabled，轨道 Border/Default

Figma 中创建方式:
  1. 用 Rectangle 模拟轨道（宽度用百分比变量表示当前值）
  2. 用 Ellipse 作为 Thumb，居于轨道上方
  3. 使用 Component Property 设置「滑块位置」变量（0%–100%）
  4. 标注: ⚠️ SwiftUI Slider() 原生组件，样式跟随系统

⚠️ Figma 标注: SwiftUI: Slider(value: $value, in: min...max)
                  仅设置 accentColor 以匹配设计规范，其余样式系统托管
```
