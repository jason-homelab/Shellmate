## Screen 12 — 覆层 O01：终端内搜索栏

### 12-A：覆层规格

```
类型: Overlay（非模态，不遮挡终端输入）
位置: 终端内容区右上角，距右边缘 12pt，距上边缘 8pt
尺寸: 320 × 40pt
圆角: 8pt
背景: Surface/Elevated
边框: Border/Default 1pt
阴影: 0 8pt 24pt rgba(0,0,0,0.5)

触发: ⌘F（终端聚焦状态下）
关闭: Esc / 点击 × 按钮
动画: 见 03-动效规范（右上角淡入下滑，150ms）

⚠️ Figma 中以 Overlay 形式叠放在 TerminalPane 的右上角
   需在 TerminalPane Frame 内创建此 Frame 并设为绝对定位
```

### 12-B：搜索栏内部布局

```
Frame 尺寸: 320 × 40pt
内边距: 左 10pt 右 8pt，垂直居中
布局: 水平 Auto Layout，间距 4pt

内部元素（从左到右）:
  ├── 搜索图标: SF Symbol「magnifyingglass」11pt  Text/Disabled
  │
  ├── 搜索输入框（SearchInput）:
  │     flex-1 × 28pt，无边框，背景透明
  │     占位符: 「搜索…」  12pt SF Pro Regular  Text/Disabled
  │     内容文字: 12pt SF Pro Regular  Text/Primary
  │
  ├── 匹配计数区（MatchCount）:
  │     宽度: 52pt
  │     文字: 「3 / 12」  11pt SF Mono  Text/Tertiary  居中
  │     无匹配: 「0 / 0」  Status/Error
  │     示例: 「─」（空状态，未输入时）
  │
  ├── 功能按钮组（Auto Layout，间距 1pt）:
  │     分割线 1pt × 18pt Border/Subtle
  │
  │     [Aa] 大小写敏感按钮（ToggleBtn）:
  │       尺寸: 26 × 26pt  圆角 4pt
  │       Label: 「Aa」  11pt SF Pro SemiBold
  │       未激活: 背景透明  Text/Disabled
  │       激活:   背景 Accent/Dim  文字 Accent/Default  边框 Accent/Border 1pt
  │
  │     [.*] 正则模式按钮（ToggleBtn）:
  │       尺寸: 26 × 26pt  圆角 4pt
  │       Label: 「.*」  11pt SF Mono
  │       状态同 [Aa]
  │
  │     分割线 1pt × 18pt Border/Subtle
  │
  │     [↑] 上一个匹配:
  │       SF Symbol「chevron.up」  IconBtn 24 × 26pt  圆角 4pt
  │       Text/Secondary；无匹配时 Text/Disabled 禁用
  │
  │     [↓] 下一个匹配:
  │       SF Symbol「chevron.down」  IconBtn 24 × 26pt  圆角 4pt
  │       Text/Secondary；无匹配时 Text/Disabled 禁用
  │
  └── [×] 关闭按钮:
        SF Symbol「xmark」  IconBtn 24 × 26pt  圆角 4pt
        Text/Tertiary；Hover: Text/Primary，背景 Surface/Overlay
```

## Screen 13 — 覆层 O02：Compose Pane（命令编辑区）

### 13-A：覆层规格

```
类型: Dockable Panel（停靠于终端区域底部）
位置: TerminalPane 底部，将终端内容区向上压缩
默认高度: 120pt
高度范围: 60pt（最小）—200pt（最大）
宽度: 与 TerminalPane 同宽（flex）

触发: 工具栏 SF Symbol「text.alignleft」按钮 / View → Compose Pane
关闭: 再次点击工具栏按钮

拖拽调整: 顶部 4pt 高度的拖拽把手（ResizeHandle）

Figma 布局: 在 TerminalPane 的 Vertical Auto Layout 中，
           QuickCmdBar 上方插入此组件，TerminalContent 高度相应减少
```

```
Frame 尺寸: flex-w × 120pt（可变）

子区域（从上到下）:
  ① ResizeHandle    flex-w × 4pt
  ② CodeEditorArea  flex-w × flex-1

```

## Screen 15 — 终端内容区键盘交互

### 15-A：终端输入模式

```
终端内容区（TerminalContent）直接接收键盘输入：
  - 无独立输入框，用户直接在终端区域输入
  - 焦点状态：点击终端区域获取焦点
  - 光标显示：块状光标（Block Cursor），7×14pt

输入行为：
  - 普通字符：直接发送至 SSH 通道
  - Return：发送 \r（回车）
  - Backspace：发送删除字符
  - 方向键：发送 ANSI 转义序列（↑=\e[A, ↓=\e[B, →=\e[C, ←=\e[D）
  - Tab：发送制表符（自动补全）
  - Ctrl+C：发送中断信号 (0x03)
  - Ctrl+D：发送 EOF
  - 粘贴 (⌘V)：发送剪贴板内容

⚠️ 设计要点：
  终端无底部输入框，采用原生终端交互方式
  QuickCmdBar 为预设命令快捷按钮，非命令输入框
```

### 15-B：终端焦点状态

```
焦点指示（终端区域边框）:
  无焦点: 无额外边框
  有焦点: 内边框 1pt rgba(Accent/Default, 0.3)

光标样式:
  类型: 块状光标（Block）
  尺寸: 7 × 14pt
  颜色: Terminal/Cursor (rgba(255,255,255,0.8))
  动画: 闪烁 opacity 0↔1, 1.1s step-end infinite

⚠️ Figma 标注:
  光标在 Figma 中用矩形表示，标注闪烁动画参数
  实际渲染由 NSTextView/SwiftTerm 处理
```

### 15-C：开发标注

```
┌─────────────────────────────────────────────┐
│  📌 开发标注（终端键盘输入）                   │
│  组件: NSViewRepresentable + NSTextView     │
```
