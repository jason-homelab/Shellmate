## 一、Segmented Control（分段控制）

**使用位置：** D01 弹窗内 Tab 导航（基本连接 / 认证 / 高级 / 外观）

### 规格

```
尺寸: 满弹窗内宽（504pt）× 28pt
背景容器: Surface/Panel  圆角 6pt  内边距 2pt

Segment 项（均分宽度，每项约 126pt × 24pt）:
  圆角: 5pt
  
  未激活态:
    背景: 透明
    文字: 12pt SF Pro Regular  Text/Tertiary
    
  激活态:
    背景: Surface/Elevated
    文字: 12pt SF Pro Medium  Text/Primary
    阴影: 0 1pt 3pt rgba(0,0,0,0.2)

  Hover（非激活）:
    背景: Surface/Overlay（比容器略亮）
    文字: Text/Secondary

切换动画（见 03-动效规范）:
  激活背景块在 Segment 之间滑动
  持续: 150ms  ease-out

⚠️ Figma 标注: SwiftUI: Picker(.., style: .segmented)
                  实际样式由系统控制，Figma 为近似效果
⚠️ Figma 实现: 使用 Auto Layout 横排，激活项覆盖一个白色 Filled Rectangle
```

### 变体清单

```
Segmented/4-Items/Default     ← D01 四标签（基本/认证/高级/外观）
Segmented/3-Items/Default     ← 按需，如三选项场景
Segmented/2-Items/Default     ← 如 本地/远程 二选一
Segmented/*/Item/Active
Segmented/*/Item/Inactive
Segmented/*/Item/Hover
Segmented/*/Item/Disabled
```

## 二、Slider（滑块）组件

**使用位置：** S02 字号（8–32pt）、行间距（0.8–2.0）、背景透明度（0–100%）

### 规格

```
整体: 高 20pt  宽 flex（跟随父容器）

轨道（Track）:
  整体轨道: 高 4pt  圆角 2pt  背景 Border/Default
  已填充段（ActiveTrack）: 背景 Accent/Default  圆角 2pt
    宽度由「当前值占总范围的百分比」决定

拇指（Thumb）:
  尺寸: 18 × 18pt  圆形
  背景: #FFFFFF（深色模式）/ #FFFFFF（浅色模式）
  阴影: 0 1pt 3pt rgba(0,0,0,0.35)
  位置: 中心与 ActiveTrack 右端对齐

聚焦状态:
  Thumb 外侧聚焦环: 3pt Accent/Default 透明度 50%

禁用状态:
  ActiveTrack 颜色: Text/Disabled
  Thumb 颜色: 去除阴影，用 Border/Default 替代白色
  Cursor: 默认（不可拖拽）

Figma 设置步骤:
  1. 创建名为 Slider/Default 的 Component
  2. 使用 Component Properties:
     - value (Number 0–100，表示百分比)
  3. ActiveTrack 宽度 = 容器宽 × (value/100)（用 Fill 层实现）
  4. Thumb 的 X 位置 = ActiveTrack 宽度 - 9pt（thumb 半径）

⚠️ Figma 限制: Figma 无法真正「响应」属性改变尺寸，
   需创建多个预设状态（0% / 25% / 50% / 75% / 100%）
   在设计稿中选择合适的状态展示
⚠️ 开发标注: SwiftUI Slider(value: $val, in: lo...hi)
              .accentColor 已在系统层面设置，无需手动指定
```

## 三、认证方式卡片（AuthMethodCard）

**使用位置：** D01 弹窗「认证」Tab，选择 SSH Key / 密码 / Agent 认证方式

### 规格

```
卡片容器（3 个并排，Auto Layout 水平，间距 10pt）:
  每卡片: 宽约 154pt × 70pt（在 504pt 内三等分）
  圆角: 8pt
  内边距: 12pt

卡片内部（Vertical Auto Layout，间距 6pt，居中对齐）:
  图标区:
    尺寸: 32 × 32pt 圆形背景
    圆形背景: Surface/Overlay  圆角 16pt
    SF Symbol 图标: 16pt，居中

  标签文字:
    11pt SF Pro Medium  居中

未选中态:
  背景: Surface/Panel
  边框: Border/Subtle  1pt
  图标背景: Surface/Overlay
  图标色: Text/Secondary
  标签色: Text/Secondary

选中态:
  背景: Accent/Dim
  边框: Accent/Border  2pt
  图标背景: rgba(Accent, 0.2)
  图标色: Accent/Default
  标签色: Accent/Default

Hover（非选中）:
  背景: Surface/Overlay
  边框: Border/Default

三种认证卡片内容:
  SSH Key:
    图标: SF Symbol「key.fill」
    标签: 「SSH Key」
    
  密码:
    图标: SF Symbol「lock.fill」
    标签: 「密码」

  SSH Agent:
    图标: SF Symbol「person.badge.shield.checkmark.fill」
    标签: 「Agent」

组件命名:
  AuthCard/SSHKey/Default
  AuthCard/SSHKey/Selected
  AuthCard/SSHKey/Hover
  AuthCard/Password/*  （同上）
  AuthCard/Agent/*    （同上）

⚠️ Figma 标注: SwiftUI 自定义 GroupBox 或 Button，无原生对应组件
```

## 四、ColorSwatch（颜色预览控件）

**使用位置：** S01 高亮规则颜色选择、S02 光标颜色

### 规格

```
尺寸: 24 × 24pt  圆角 4pt
边框: Border/Default  1pt

内部分区（水平）:
  颜色展示区（左 18pt）:
    填充: 目标颜色（实际颜色值）
    
  触发箭头区（右 6pt）:
    背景: 目标颜色加深 15%（暗化）
    图标: SF Symbol「chevron.down」或三角形  6pt  白色  opacity 0.7

交互:
  点击整个控件: 触发系统 NSColorPanel
  Hover: 边框变 Border/Strong

特殊状态 — 透明色（「无背景」选项）:
  棋盘格纹纹理（表示透明）
  棋盘格: 4×4pt  颜色: rgba(白,0.15) 与 rgba(白,0) 交替

状态变体:
  ColorSwatch/Filled/Default     ← 有颜色
  ColorSwatch/Filled/Hover
  ColorSwatch/Transparent        ← 无背景色
  ColorSwatch/Focused            ← 输入框聚焦环

⚠️ 标注: NSColorWell（AppKit），SwiftUI ColorPicker()
   触发 NSColorPanel（系统颜色选择器）
```

## 五、ProgressBar（传输进度条）—补充细节

**使用位置：** SFTP 传输队列各传输项（补充 01-界面布局规范中的说明）

```
尺寸: 满行宽（约 274pt）× 3pt

轨道:
  背景: Surface/Overlay  圆角 2pt

填充动画:
  Active（传输中）:
    颜色: Accent/Default
    圆角: 2pt（左端圆角匹配轨道）
    Shimmer 光效（见 03-动效规范 §2.6）

  Paused（暂停）:
    颜色: Accent/Default  opacity 40%
    无 Shimmer 动画

  Completed（完成）:
    颜色: Status/Connected  100% 宽度
    图标切换为 ✓（见动效规范 §2.6 传输完成）

  Failed（失败）:
    颜色: Status/Error
    宽度保持失败时的百分比（不清零）

Figma 组件:
  ProgressBar/Active/0%
  ProgressBar/Active/33%
  ProgressBar/Active/67%
  ProgressBar/Paused/*
  ProgressBar/Completed
  ProgressBar/Failed/*
```

## 六、NumberInput（数字步进器）

**使用位置：** D04 端口输入、S02 外观内边距、O02 发送延迟

```
尺寸: 高 28pt  宽: 按需（端口输入 60pt，延迟输入 44pt，内边距 46pt）
背景: Surface/Input
边框: Border/Default  1pt  圆角 5pt

内部布局（水平，间距 0）:
  输入区（flex-1）:
    字体: 11pt SF Mono  Text/Primary  居中
    仅允许数字输入
    
  步进按钮（选配，视场景而定）:
    宽度: 20pt × 2（各占 10pt，垂直叠放）
    上下箭头: SF Symbol「chevron.up」「chevron.down」  7pt  Text/Disabled
    Hover: Text/Secondary，背景 Surface/Overlay
    右圆角: 5pt

状态:
  Default:  背景 Surface/Input，边框 Border/Default
  Focus:    边框 Accent/Border  2pt，聚焦环 3pt
  Error:    边框 Status/Error，背景 Status/Error 透明度 10%
  Disabled: 背景 Surface/Elevated，文字 Text/Disabled

⚠️ Figma 标注:
  SwiftUI TextField(value: $val, formatter: NumberFormatter())
  .keyboardType(.numberPad) on macOS 无效，直接限制输入字符
```

## 七、EmptyState（空状态）

**使用位置：** 侧边栏无会话、搜索无结果、D05 命令未选中、Known Hosts 无记录等

### 通用规格

```
容器: 垂直居中于父容器（使用 Spacer 的 VStack）
内部 Auto Layout（垂直，居中对齐，间距 8pt）:

图标:
  SF Symbol  32pt（大）或 22pt（小）
  颜色: Text/Disabled  opacity 0.4

主文字:
  12pt SF Pro Medium  Text/Disabled
  
副文字（可选）:
  11pt SF Pro Regular  Text/Disabled  opacity 0.75
  最大宽度: 200pt  居中，自动换行

操作按钮（可选）:
  Button/Bordered 高 28pt
  margin-top: 6pt（与副文字间距略大）
```

### 场景变体

```
EmptyState/Sidebar（侧边栏无会话）:
  图标: SF Symbol「externaldrive.fill」32pt
  主文字: 「还没有保存的会话」
  副文字: 「点击下方按钮创建第一个 SSH 会话」
  按钮: 「＋ 新建会话」

EmptyState/Search（搜索无结果）:
  图标: SF Symbol「magnifyingglass」22pt
  主文字: 「未找到相关会话」
  副文字: 「尝试其他关键词或 IP 地址」
  无按钮

EmptyState/SFTP（SFTP 目录为空）:
  图标: SF Symbol「folder」28pt
  主文字: 「此目录为空」
  无副文字，无按钮

EmptyState/KnownHosts（无记录）:
  图标: SF Symbol「server.rack」28pt
  主文字: 「尚无已记录的服务器指纹」
  副文字: 「连接新服务器时，指纹记录将自动添加到此列表」
  无按钮

EmptyState/Commands（D05 未选中命令）:
  图标: SF Symbol「text.cursor」28pt
  主文字: 「选择左侧命令进行编辑」
  无副文字，无按钮
```

## 八、SkeletonLoader（骨架屏加载态）

**使用位置：** SFTP 面板目录加载中、会话列表首次加载

```
用途: 替代 Loading Spinner，减少布局跳动感

Skeleton 元素外观:
  颜色: Border/Default 透明度 60%
  圆角: 与替代内容的圆角一致（文字行用 4pt，图标用 圆角 8pt）

  Shimmer 动画（全局横扫）:
    底色: Border/Default 透明度 60%
    光带: 从左到右，宽度 40pt
    光带颜色: Border/Subtle（比底色略亮）
    动画: 持续 1.5s，无限循环
    Reduce Motion: 移除光带，保持底色

SFTP 骨架屏（FileListSkeleton）:
  SkeletonRow × 5（模拟文件行）:
    行高: 30pt
    元素（水平，间距 10pt）:
      ├── 图标占位: 14×14pt  半透明矩形  圆角 3pt
      ├── 名称占位: flex-1 × 10pt  圆角 4pt（居中于 30pt 行高）
      │     宽度随机 60%–90%（Figma 中创建多个不同宽度的变体）
      ├── 大小占位: 40pt × 8pt  圆角 3pt  右对齐
      └── 日期占位: 60pt × 8pt  圆角 3pt  右对齐

侧边栏骨架屏（SidebarSkeleton）:
  分组标题占位 × 1:
    宽 80pt × 8pt  圆角 3pt  margin: 8pt 12pt 4pt
  SessionRowSkeleton × 3:
    行高: 44pt  内边距 10pt 12pt
    ├── 状态点占位: 6×6pt  圆形
    ├── 名称占位: 80–120pt × 10pt  圆角 4pt
    └── 徽章占位: 28 × 14pt  圆角 3pt  右对齐

⚠️ Figma 标注:
   SwiftUI: 使用 .redacted(reason: .placeholder) 修饰符
   配合 ShimmerEffect ViewModifier（自定义实现）
```
