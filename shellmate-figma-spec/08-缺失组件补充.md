## 一、Segmented Control（分段选择器）

```
容器:
  背景: bg-black/5 + backdrop-blur-sm
  圆角: rounded-xl（12pt）
  内边距: p-1（4pt）

选中项（TabsTrigger[data-state=active]）:
  背景: bg-white（Light）/ bg-[#1C1C1E]（Dark）
  阴影: shadow-sm
  圆角: rounded-lg（8pt）
  过渡: all duration-200

未选中项:
  背景: transparent
  圆角: rounded-lg
  hover: bg-black/5

文字:
  字体: 12pt SF Pro medium
  颜色: #1d1d1f（选中）/ #86868b（未选中）
```

## 二、认证方式卡片（AuthMethodCard）

```
布局: HStack（3等分，gap-2.5）
  每张卡片: frame(maxWidth: .infinity, height: 70pt)

卡片结构（VStack，spacing: 8pt）:
  [图标圆圈] w-8 h-8 rounded-full
    选中: bg-accentPrimary/20
    默认: bg-surfaceOverlay
    图标: 16pt，选中→accentPrimary / 默认→textSecondary

  [标签] 11pt SF Pro medium
    选中: accentPrimary
    默认: textSecondary

卡片背景:
  选中: accentPrimary/8%
  默认: surfacePanel
圆角: clipShape RoundedRectangle cornerRadiusSmall continuous
边框:
  选中: accentPrimary 2pt
  默认: borderSubtle 1pt
```

认证方式枚举：

| Method | 图标 | displayName |
|--------|------|-------------|
| `.password` | `lock.fill` | 密码 |
| `.privateKey` | `key.fill` | 私钥 |
| `.sshAgent` | `person.badge.key.fill` | SSH Agent |
| `.keyboardInteractive` | `keyboard` | 键盘交互 |

## 三、AI 助手面板（AIAssistantPanel）

### 3.1 面板整体

```
宽度: 400pt（w-[400px]）
位置: 终端区左侧，border-r #d2d2d7/50
背景: #FFFFFF/90 + backdrop-blur-xl
阴影: shadow-lg（右侧）

整体 VStack:
  Header（固定）
  Messages 区（flex-1，ScrollArea）
  Quick Prompts（条件显示）
  Input 区（固定）
```

### 3.2 Header

```
内边距: p-4（16pt）
背景: #FFFFFF/60 + backdrop-blur-xl
边框: border-b #d2d2d7/50

内容 HStack（gap-2）:
  [图标容器] p-2 rounded-xl
    背景: gradient-to-br from-[#007aff] to-[#5856d6]
    阴影: shadow-lg
    图标: Sparkles h-5 w-5 white

  [文字区] flex-1
    标题: "AI 助手"  font-semibold 14pt #1d1d1f
    副标题: "正在协助 {sessionName}" text-xs #86868b
```

### 3.3 消息气泡

**用户气泡（右对齐）**
```
布局: flex justify-end gap-3
气泡: max-w-[85%] rounded-2xl px-4 py-3
  背景: #007aff
  文字: white text-sm whitespace-pre-wrap
用户头像: w-8 h-8 rounded-full bg-[#86868b]
  内容: "U" text-sm font-medium white
```

**AI 气泡（左对齐）**
```
布局: flex justify-start gap-3
AI 头像: w-8 h-8 rounded-full
  背景: gradient from-[#007aff] to-[#5856d6]
  图标: Sparkles h-4 w-4 white
  阴影: shadow-md
气泡: max-w-[85%] rounded-2xl px-4 py-3
  背景: #FFFFFF/80 + backdrop-blur-sm
  边框: #d2d2d7/50
  阴影: shadow-sm
  文字: #1d1d1f text-sm whitespace-pre-wrap
```

**命令块（AI 气泡内）**
```
每条命令: flex items-center gap-2 mt-2
  背景: bg-black/5 + backdrop-blur-sm
  圆角: rounded-lg（8pt）
  内边距: p-2
  边框: #d2d2d7/30

  [命令文字]: flex-1 text-xs font-mono #1d1d1f break-all
```

**打字指示器**
```
3个小圆点: w-2 h-2 rounded-full bg-[#86868b] animate-bounce

```

## 四、SFTP 文件传输面板（FileTransferPanel）

### 4.1 面板整体

```
宽度: 500pt
位置: 终端区右侧，border-l #d2d2d7/50
背景: #FFFFFF/50 + backdrop-blur-xl
布局: VStack（Header + 双栏浏览器 + 底部状态）
```

### 4.2 Header

```
内边距: p-3
背景: #FFFFFF/60 + backdrop-blur-xl
阴影: shadow-sm
边框: border-b #d2d2d7/50

标题行（HStack justify-between）:
  文字: "文件传输 - {sessionName}" text-sm font-semibold #1d1d1f
  按钮组（gap-2）:
    [上传↑] h-7 px-3 text-xs rounded-lg hover:bg-black/5
            disabled: 无选中本地文件或传输中
    [下载↓] h-7 px-3 text-xs rounded-lg hover:bg-black/5
            disabled: 无选中远程文件或传输中

进度条（传输中显示）:
  容器: bg-white/80 rounded-lg p-2
  进度文字: text-xs #86868b
  进度条: h-1.5 rounded-full（使用 Progress 组件）
```

### 4.3 双栏文件浏览器

```
布局: flex-1 grid-cols-2 divide-x divide-[#d2d2d7]/50

每栏结构:
  [栏 Header] p-2 bg-white/60 backdrop-blur-xl border-b
    标题行（HStack）:
      [图标容器] p-1 rounded-md
        本地: bg-[#007aff]/10, HardDrive icon, #007aff
        远程: bg-[#34c759]/10, Server icon, #34c759
      文字: text-xs font-semibold #1d1d1f
      [操作按钮] h-6 w-6 rounded-md:
        新建文件夹: FolderPlus h-3 w-3
        删除: Trash2 h-3 w-3（disabled: 无选中）

    [路径输入栏]:
      bg-white/90 rounded-lg px-2 py-1.5 border #d2d2d7/50
      Home icon h-3 w-3 #86868b
      input: text-xs bg-transparent flex-1
      [刷新按钮]: h-5 w-5 rounded-md, RefreshCw h-3 w-3

  [文件列表] ScrollArea flex-1 p-1.5
```

### 4.4 文件行（FileItem Row）

```
布局: button w-full flex items-center gap-2 px-2 py-1.5 rounded-lg
过渡: all duration-200

选中态:
  本地: bg-[#007aff]/10 border border-[#007aff]/30 shadow-sm
  远程: bg-[#34c759]/10 border border-[#34c759]/30 shadow-sm
默认 hover: bg-black/5

内容（HStack）:
  [图标容器] p-1 rounded-md
    目录: bg-[#007aff]/10, FolderOpen h-3.5 w-3.5 #007aff
    文件: bg-[#86868b]/10, File h-3.5 w-3.5 #86868b

  [文字区] flex-1 min-w-0
    文件名: text-xs font-medium #1d1d1f truncate
    元信息: text-xs #86868b（大小 + 修改日期，gap-2）

  ChevronRight（仅目录）:
    h-3 w-3 #86868b
    opacity-0 group-hover:opacity-100 transition-opacity
```

### 4.5 底部状态栏

```
内边距: p-2
背景: #FFFFFF/60 + backdrop-blur-xl
边框: border-t #d2d2d7/50

布局: flex items-center justify-between text-xs #86868b
  左: "本地: {选中}/{文件数} 个文件"
  Separator vertical h-4
  右: "远程: {选中}/{文件数} 个文件"
```

## 六、密码管理器弹窗（PasswordManagerDialog）

```
Dialog: max-w-[480pt] rounded-2xl bg-white/95 backdrop-blur-2xl

会话-密码列表:
  每行: HStack
    会话名（font-medium）+ user@host（text-xs SF Mono）
    flex-1
    [删除] Button variant-ghost size-sm text-[#ff3b30]

空状态:
  居中文字: "没有已保存的密码" text-sm #86868b
```

## 七、分组管理弹窗（GroupManagementDialog）

```
Dialog: max-w-[400pt] rounded-2xl bg-white/95 backdrop-blur-2xl

[新建分组] 输入行:
  TextField + [新建] Button（#007aff）

分组列表:
  每行: 📁 文件夹名 + [删除] Button（红色，二次确认）
  删除确认: 提示"此操作会将该分组内会话移至未分组"
```

## 八、会话导入/导出弹窗（SessionImportExportDialog）

```
Dialog: max-w-[480pt] rounded-2xl bg-white/95 backdrop-blur-2xl

两个操作区:
  导出: 展示当前会话列表（去除密码字段）+ [导出 JSON] Button
  导入: 文件拖拽区 or [选择文件] + 预览 + [确认导入] Button

格式: JSON，字段 = Session 模型（不含密码）
```
