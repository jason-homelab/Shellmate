## 3. Feedback 视觉规格

### 3.1 Toast（短时反馈，自动消失）

| 属性 | 值 |
|---|---|
| 高度 | 44pt 单行 / 高度自适应多行 ≤ 80pt |
| 最大宽度 | 360pt |
| 圆角 | 10pt（新 cornerRadiusToast） |
| 内边距 | 12pt × 16pt |
| 阴影 | `e3` |
| 左侧 icon | 16×16pt（feedback level icon） |
| icon 与文字间距 | 10pt |
| 文字 | `mono.dataSM` 或 system 13pt |
| 入场 | y -16pt + opacity 0→1 / 280ms spring(0.4, 0.85) |
| 出场 | opacity 1→0 + scale 1→0.96 / 200ms easeOut |
| 默认 lifetime | 3000ms |
| 堆叠 | 最多 3 个，间距 8pt，第 4 条来时最旧 dismiss |
| 位置 | 窗口右上，距 toolbar 底部 12pt，距右边 16pt |

### 3.2 Banner（持续显示，需用户操作）

| 属性 | 值 |
|---|---|
| 高度 | 56pt 起步，自适应 |
| 圆角 | 12pt |
| 左侧 indicator 条 | 4pt 宽 × 全高，level 实色 |
| 内边距 | 14pt × 16pt |
| 边框 | 1pt + feedback{level}Border |
| Action 按钮 | PillButtonStyle.normal / .primary，最多 3 个，间距 8pt |
| 关闭按钮 | 右上 ×（16×16）|

### 3.3 Action 类型

```swift
.retry              -> 主按钮 "重试"
.editCredentials    -> "重新输入密码"
.acceptHostKey      -> "接受并继续" + 警告色
.testNetwork        -> "检查网络"
.dismiss            -> "知道了"
.openSettings(tab)  -> "打开 {tab} 设置"
```

## 6. State Machine 视觉矩阵摘要

### 6.1 TerminalConnectionState

| State | 状态点 | 中央 Overlay | 工具栏 |
|---|---|---|---|
| idle | 灰空圆 | — | 蓝色"连接" |
| connecting(.dns/tcp/handshake/auth) | 黄脉冲 1.0s 周期 | 4 阶段 stepper | 灰"连接中"+ spinner |
| connected | 绿实心+glow | — | 红色"断开" |
| reconnecting(attempt) | 橙脉冲 0.6s | 大号"重新连接 (N/5)"+ 倒计时 | 灰"重连中" |
| disconnected(.networkLost) | 红 | 红 banner + "重连"主按钮 | 蓝"连接" |
| failed(.auth) | 红 | ConnectionErrorView + actions | 蓝"连接" |

### 6.2 TabLifecycleState

| State | Tab 显示 | 关闭行为 |
|---|---|---|
| active(.idle) | 标准选中 | 直接关闭 |
| active(.runningCommand) | + 标题左蓝点 | 弹 confirm |
| active(.error) | + 标题左红点 | 弹 confirm |
| background(.unreadOutput) | 灰底 + 右侧蓝 badge | 直接关闭 |
| closing | opacity 1→0.4 + scale 1→0.92 | — |
| closed(.recoverable) | 不显示，进入"最近关闭"⌘⇧T 列表 | — |

## 10. 工具栏重组规格

```
左：[⏻ 连接]   中：· session-name ·   右：[✦ AI（渐变）] [工具▾]
```

- AI 按钮：背景 `Gradients.aiButton @ 12%` 常态、@ 22% hover；边框 `accentAI @ 30%`
- 「工具▾」菜单分区：📁 文件 / 🔀 网络 / 📜 自动化 / 📊 监控
- 菜单顶部加 "搜索操作... ⌘K" 横条 → 触发 Command Palette
- 智能折叠：窗口 ≤ 1200pt 折叠常用项至「工具▾」
