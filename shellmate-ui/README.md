# ShellMate — 主界面视觉设计稿

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 主界面 HTML 结构 |
| `styles.css` | 完整视觉设计系统（CSS 变量 + 组件样式） |
| `interactions.js` | 微交互脚本（标签切换、分组折叠、进度动画） |

## 设计决策

### 审美方向
**工业暗黑 · 精密质感**

- 背景使用接近 OLED 纯黑的深色系（`#080809` → `#111115`），而非常见的灰黑
- 通过多层透明叠加（而非渐变）创造表面深度
- 唯一强调色：电光蓝 `#3d8ef0`，在黑色背景上形成锋利对比
- 状态颜色（绿/黄/红）保持高饱和度，确保可读性的同时点缀界面

### 字体组合
- UI 文字：**Geist**（Vercel 出品，几何感与可读性的极佳平衡）
- 终端/代码：**Geist Mono**（等宽，字符密度适合大量信息）

### 设计令牌
所有颜色均通过 CSS Variables 管理，在 `styles.css` 顶部 `:root` 块中定义，方便主题切换。

### 信息层级
1. 终端内容区（最高优先级，最大空间，最低干扰背景）
2. 侧边栏（次级，提供上下文但不抢夺视线）
3. 状态栏（最低层级，仅在需要时引起注意）

## 使用方式

直接用浏览器打开 `index.html` 即可查看设计稿。
建议使用 Chrome 或 Safari，窗口宽度 ≥ 1200px 以获得最佳效果。
